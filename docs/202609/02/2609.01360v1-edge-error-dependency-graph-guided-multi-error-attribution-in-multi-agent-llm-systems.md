## 摘要
大型语言模型（LLM）智能体的失败往往包含多个相关错误，而非单一失误。现有归因方法通常识别责任智能体、步骤或根本原因，但未显式建模错误之间的依赖关系。我们提出EDGE，一种基于错误依赖图的多样化错误归因框架。EDGE从观察到的错误事件构建错误依赖图，并通过反事实推演验证可靠因果子集。推理图引导两阶段LLM作为评判器的检测器进行错误归因，而经过干预验证的子图为解释和修复分析提供更可靠基础。在TRAIL和MAST上的实验表明，EDGE在大多数评估模型和设置中提升了类别级多样化错误归因性能。采用改编Who&When风格提示的实验显示，该图在不同提示策略下均有效。这些结果表明，依赖结构是智能体失败的实用诊断先验，超越了孤立的根本原因预测。

## Abstract
Large language model (LLM) agent failures often contain multiple related errors rather than a single mistake. Existing attribution methods usually identify a responsible agent, step, or root cause, but do not explicitly model dependency between errors. We introduce EDGE, an Error Dependency Graph-guided multi-Error attribution framework. EDGE constructs an error dependency graph from observed error events and validates a reliable causal subset through counterfactual rollout. The inference graph guides a two-stage LLM-as-judge detector for error attribution, and the intervention-validated subgraph provides a more reliable basis for explanation and repair analysis. Experiments on TRAIL and MAST show that EDGE improves category-level multi-error attribution across most evaluated models and settings. Experiments with adapted Who&When-style prompts show that the graph helps across prompting strategies. These results suggest that dependency structure is a useful diagnostic prior for agent failures beyond isolated root-cause prediction.

# EDGE：基于错误依赖图的多智能体 LLM 系统多错误归因

## 1. 核心问题与研究动机

**背景：**
- 大语言模型（LLM）智能体常被用于复杂多步任务，涉及规划、检索、工具调用和推理。一旦执行失败，最终结果只能表明“失败”，却无法解释失败是如何逐步演化的。
- 现有失败归因研究通常聚焦于**单一错误归因**——找出“哪个智能体/哪一步/哪个根因”导致了失败（如 Who&When、AgentErrorBench、CDC-MAS、CHIEF 等）。它们没有显式建模错误之间的传播与依赖。
- TRAIL 等新型基准开始提供**细粒度的多错误标注**（span-level），显示一次失败中往往存在多个结构性角色不同的错误：上游触发、下游后果、平行症状。然而单错误方法被扩展为多标签输出时，通常将各错误视为孤立目标，忽视了“一个错误可能使另一个错误更可能发生”的依赖结构。

**核心研究问题：**
> 如何在 LLM 智能体轨迹中，将**多错误归因**建模为**依赖感知的诊断**——即构造并利用错误类别之间的依赖/传播图，实现更准确、可解释的多错误归因？

**总体思路：** EDGE 利用轨迹内的错误时间顺序与跨轨迹的规律性，推断错误类别间的传播结构（错误依赖图），再引导 LLM 检测器分阶段归因——第一阶段预测初始错误，第二阶段根据图的依赖关系验证可能的下游错误。论文的核心主张是：**错误依赖结构是超越“孤立根因预测”的有效诊断先验。**

## 2. 方法论

### 2.1 问题形式化
- 轨迹 T = (s₁,…,s_N) 为按时间排序的跨度序列，每个轨迹标注错误事件 E(T) 由（错误类别 c，起始跨度 ℓ）构成。
- 任务：为每条轨迹预测所有（类别-位置）对，即多错误归因（multi-error attribution）。错误类别 C 可来自任意多错误错误分类系统，方法保持分类学无关。

### 2.2 错误依赖图的构建（三阶段）
1. **观测相关图 G_S（Suppes 筛选）**
   - 针对候选定向错误对 A→B，检查两条规则：
     - **时间优先**（Temporal Priority）：A 首次出现必须早于 B。
     - **概率提升**（Probability Raising）：P(B|A) 显著高于 P(B|¬A)。
   - 边权重采用两分数的几何均值 w_S(A,B) = √(Prec(A,B)·ΔPR(A→B))。
   - 输出为观测相关图 G_S = (C, R_S)，含所有 Suppes 筛选后的边。
2. **因果候选图 G_C（CAPRI / AIC 剪枝）**
   - 在 G_S 的有向无环子图空间中搜索，用 AIC 式评分（二值事件模型的似然 + 参数惩罚）进行结构剪枝（hill-climbing 边增删反转），得到更稀疏的因果候选图，输出给干预验证。

3. **基于干预的因果验证（得到验证图 G_V）**
   - 对每个因果候选边 A→B，取 t_A < t_B 的轨迹，对源错误 A 施加“补丁”干预（由类别专属修复模块 + LLM 判定 Judge A 确认 A 是否真被消除；工具输出保持不变以确保仅推理路径变化），进行反事实重跑（counterfactual rollout）。
   - 结果由判定员 Judge B 评估目标错误 B 是否复现，估计风险差 Δ(A→B)＝E[X_B(原轨迹)−X_B^(cf)(反事实轨迹)]。
   - 当 Δ(A→B) > τ_val 时保留边，形成**干预验证边界子图 G_V**（因果可信锚）。

### 2.3 推理图构建
- 由于干预验证限于可用样本，G_V 可能缺乏观测上很强的关联，因此将 G_V 与评分过筛的观测边并集为 **推理图 G_τ**：
  - R_τ = {A→B ∈ R_S : w_S(A,B) ≥ τ} ∪ R_V。
  - 边的传播权重 w_AB 对验证边采用 Δ(A→B)，对纯观测边采用 w_S。
- EDGE 的默认检测输入为 G_τ（验证 ∪ 分数筛选相关边）；G_V 仅作为替代/消融并使用于解释。

### 2.4 两阶段图引导的误错检测（EDGE Trace-Conditioned Graph Guidance）
1. **Stage 1（初始检测）**：LLM 法官给定轨迹、分类学和图 G_τ，预测初始错误集合。
2. **追溯激活图**：D(T) ＝ Stage-1 预测的错误类别；依据图 G_τ，将所有“源已检测→目标未检测”的边保留，聚合权重超过阈值 τ_GI 的下游假设形成轨迹特化边子集 R_τ^(T)。
3. **Stage 2（验证下游错误）**：法官收到提示：已知预测集合 + 图建议的下游类别，只输出类别不在 D(T) 中的新错误。
4. **合并**最终预测：Stage 1 ∪（Stage 2 中未被 Stage 1 覆盖的类别），实现类别级去重。

## 6. 主要结论与发现

- **EDGE 能显著提升多错误归因的类别检测**：在 TRAIL 上加权-F1 大多大幅改进（开源骨干最多在 SWE-Bench 上改善 ≥20 个百分点；GPT-5 在其最强的基准上保持优势），而 SWE-Bench 上的精确率定位很困难（Loc/Joint 数字维持低水平）。Gemini-2.5-Pro 在 GAIA 上的表现水平相当高。
- **图形引导可转移并在 trace-level 上有益**（MAST）：加权的 F1 在 GPT-4o 多数开源骨干上均上升。代价是可预料的准确率-召回率权衡：准确率下降（在 MAST 13 类预测上，因为为 always-no 的普遍分类器准确率较高），但召回率上升。从性能和测试视角所见的偏斜性表现为准确率不适合单独解读。
- **动态两阶段使用是核心杠杆**：+CG 用同样的全套边集作为单次静态阶段，效果不稳定（与 baseline 比多数情况下帮助不大），而 EDGE 在 15 个测试单元中 14 个优于 +CG。*如何消费图信息（trace-condition + targeted verification）比单纯访问图更重要。*
- **图形可泛化到未见轨迹**：保留 20% 并不降低提升范围。
- **该结构支持解释性和修复优先分析**：验证图 G_V 揭示有意义的因果传播（如 TRAIL：“格式错误→上下文处理失败”→引发传播问题；MAST：“动作-推理不匹配→过早终止”）。通过修复高连射出的上游节点可避免多个下游症状，而不是只修复表面。
- **归因分析**：EDGE 的收益高度集中在规划错误和协调类别上（“EDGE 唯一 提升”最大），其次集中在推理部门。系统执行源错误受益不大，可能与这些输出在依赖拓扑中上游从属的整体角色有关。

## 7. 优点

- **新颖的问题想象**：跳出单个根因的框架，将多错误归因转化为带感知序列结构的依赖感知向量诊断。
- **清晰的三级图分工**：G_S（观测、边分数筛选）、G_C（因果候选）、G_V（因果锚，验证）、G_τ（检验推理图）——在预测覆盖与可解释的可靠性之间取得明确的平衡。
- **分类无关**：任意错误的分类法都可以用该流水线重新跑一遍，在 TRAIL 与 MAST 不同 taxonomy/span 上有结果证明。
- **清晰的设计和对照消融**：

**清晰的设计和对照消融**：EDGE 的消融设计值得肯定——通过“随机边计数对照”（random-12/random-11）证明性能提升不是单纯由更多边或更大提示带来，通过“+CG 静态引导”与 EDGE 动态两阶段的对比分离出“图的可访问性”与“按轨迹动态注入”的贡献，通过仅含干预验证边的 G_V 验证因果锚在有限标注下的可用性，并通过 80/20 保留轨迹评估说明图结构对未见轨迹有泛化能力。这种多层次、受控的对照设计为图作为“诊断先验”的核心主张提供了可信证据。

## 8. 局限性与不足

- **干预验证成本与扩展性未明确量化**：论文虽展示了反事实验证的必要性和有效性，但对每条候选边的 GPT-4o / o3-mini 调用量、token 消耗、失败率、人工审核需求均未给出系统性数据。文中仅提到“图构建是一次性预处理”，但其绝对开销和时间在真实大规模应用或动态更新的场景中可能成为瓶颈。
- **多错误归因评测的天花板与细粒度定位困难**：TRAIL-SWE-Bench 的 Loc / Joint 分数极低，说明即便类别检测有明显改善，将错误精确映射到 span 位置仍然远未解决。EDGE 本身并未提出跨度定位的专用机制，而是依赖基础 LLM 的文本理解能力，因此在长上下文、多文件代码场景下，误差会从类别层面泄漏到定位层面。
- **图构建依赖标注质量与分类学粒度**：错误依赖图建立在人工 / 模型标注的错误类别之上，若分类学本身不完整或存在误标，图结构将继承相应噪声。MAST 的部分步骤标注由 GPT-4o 自行生成（82.0% 覆盖率），且没有报告与人类标注的一致率，图构建的“起点可信度”因此受到一定削弱。
- **加权 F1 提升可能伴随准确率-召回率权衡的过度忽略**：MAST 等标签不均衡数据集上，准确率显著下降而召回率上升。虽然作者解释为“有助于发现更多真实错误”，但未讨论在假阳性成本较高的下游应用（例如代码修复中的无效警告）中这种权衡是否可接受。
- **没有给出统计显著性检验与多随机种子方差**：所有结果均为单次推理运行，缺少置信区间、显著性检验或多种子重复实验。考虑到 LLM 判别本身有波动性，这削弱了不同骨干模型之间以及阈值选择的结论强度。
- **验证图的“因果证据”仍依赖强假设**：反事实重跑中假设“对源错误的补丁修复不会改变工具输出或引入新的代理效应”，但实际智能体轨迹中，修复上游错误可能改变后续工具选择的分布，从而间接影响目标错误的复现概率一一这一影响被简单归入“无效边”，可能使验证图过于保守或遗漏间接因果路径。
- **推理图阈值的选择方法较粗糙**：τ 按所有模型的平均效果统一选取，不会针对单个骨干调节。不同模型对图提示的敏感度差异很大（实验中也能看到部分模型提升不显著甚至下降），统一阈值可能没有充分利用每个检测器的能力。
- **可解释性停留在“错误类别传播图”，未提供实例级解释**：G_V 能展示类别 A 在统计意义上引发类别 B，但对于某一条具体轨迹为何如此传播，没有给出清晰的原因链说明。用于人类审计时可能仍需要另做一层解析。

## 9. 个人思考与改进建议

- **将位置定位也纳入图引导，而不只引导类别**：EDGE 的两阶段目前仅在类别层面做下游假设生成，但最终评估对 span 定位极为严格。可以尝试为每个图节点同时维护“类别-典型跨度偏移”分布，在第一阶段预测出类别后，用该分布生成更聚焦的 span 搜索范围，从而缓解长代码上下文下的定位困难。
- **建立动态在线图更新机制而非一次性图**：在执行大规模多智能体系统时，错误类别及其依赖并非静止不变。可考虑基于在线抽取的新轨迹定期增量更新 Suppes 分数，并仅对高不确定性边进行局部干预重验证，以平衡成本与时效。
- **降低对 GPT-4o 预标注和图构建的依赖**：论文的主流程中，图构建和干预验证均指代昂贵的大模型管线。可以探索用较小模型产出的“弱监督相关候选项”初步筛选边，再用大模型做定向验证，从而降低整体成本门槛。
- **补充针对下游应用的评估**：将 EDGE 的多错误归因结果接入修复智能体，测量“按图优先级修复上游节点”对任务成功率的提升，会比单独报告 F1 更有说服力，也更能展示依赖感知归因的实际价值。
- **开展不确定性量化与显著性测试**：至少对主基线实验进行少数几次重复采样并报告方差（LLM 温度不为零时的差异），或使用 bootstrap 方法估计置信区间，使结论在统计上更稳健。

## 10. 总结

EDGE 提出了一种新颖的多错误归因范式：不把一条失败轨迹中的多个错误当作孤立标签，而是通过 Suppes 筛选、因果结构搜索与干预反事实验证构造错误类别间的传播图，再以两阶段、动态注入的 LLM 判断流程识别“初始错误+图建议的下游错误”。在 TRAIL 和 MAST 两个不同注程度、不同任务类型的基准上，EDGE 对多数开放权重与闭源骨干都带来稳定的类别级 F1 提升，且提升主要来自于动态两阶段使用图结构本身，而不是简单获取图边集。该方法在可解释的因果传播分析、修复优先级排序方面展现出潜在价值，且在保留轨迹集上表现泛化能力。但干预验证成本、位置级定位精度、统计显著性以及图构建对预标注质量的依赖等问题仍需进一步解决。总体而言，EDGE 为 LLM 智能体可诊断性研究提供了一个清晰的视角转变——**真正有价值的不是找“出一个”根因，而是理解错误如何通过系统内的结构互相触发、传播并最终导致任务失败。**
