## 摘要
人工智能代理日益执行长期推理、规划、工具使用、记忆整合和自主决策，然而错误的中间状态可能传播并导致不一致的决策和不可靠的输出。现有的推理方法主要依赖于迭代规划、自我反思、增强记忆或验证，但很少定位并选择性修复有缺陷的推理。我们提出了ORDDAR（基于观测驱动的推理，实现抗扭曲决策、行动与认知恢复），这是一个将推理建模为认知状态转换的推理框架，能够检测局部扭曲，从先前经验中检索相关推理，并仅修复受影响的状态。因此，ORDDAR在局部推理转换层面执行恢复，而不是重新生成完整轨迹。在数学、常识、多跳和临床推理基准上的实验表明，与多个评估的推理基线相比，推理质量、恢复能力和可解释性均有提升。

## Abstract
AI agents increasingly perform long-term reasoning, planning, tool use, memory integration, and autonomous decision making, yet erroneous intermediate states can propagate and cause inconsistent decisions and unreliable outputs. Existing reasoning approaches mainly rely on iterative planning, self-reflection, augmented memory, or verification, but rarely localize and selectively repair faulty reasoning. We present ORDDAR (Observation-Driven Reasoning for Distortion-Resilient Decision, Action, and Cognitive Recovery), a reasoning framework that models reasoning as cognitive state transitions, detects localized distortions, retrieves related reasoning from prior experiences, and repairs only the affected states. ORDDAR therefore performs recovery at the local reasoning-transition level rather than regenerating the complete trajectory. Experiments across mathematical, commonsense, multi-hop, and clinical reasoning benchmarks demonstrate improved reasoning quality, recovery ability, and interpretability over multiple evaluated reasoning baselines.

## 2. 论文提出的方法论

- **核心思想**：将推理过程建模为一系列**认知状态转换**，通过检测相邻认知状态之间的不协调（语义偏移 + 认知锚点偏移），定位局部扭曲，再从历史经验库（Cognitive Mirror）中检索相似故障的“恢复配套信息”，仅修复受影响的推理状态，其他正确状态保持不变。
- **问题形式化**：
  - 输入查询经观测提取函数 φ 转为观测集 O = {o₁, …, oₘ}。
  - 推理引擎逐步构建认知状态轨迹 R = {s₁, …, s_T}，状态递推为 s_t = f(s_{t-1}, o_t)。
  - 目标是学习恢复函数 F: R → R̂，得到修复后的推理轨迹。
  - 局部检查窗口定义为 W_t = {s_t, s_{t+1}}，沿轨迹滑动，逐转换进行检测和修复。
- **技术细节**：
  - **扭曲检测**：结合两种互补距离度量——语义嵌入空间中相邻状态间的余弦距离（d_sem），以及归一化认知锚点分布间的L2距离（d_anchor），两者归一化后通过根号求和方式合成联合扭曲分数 D_t。当某转换的 D_t 超过该轨迹的自适应阈值 τ_R 时，即被标记为扭曲。
  - **签名编码**：每个被标记的扭曲被编码为三元签名 k_t = {ψ_shift, A_gain, A_loss}，分别表示语义偏移、新引入的推理锚点、丢失的推理锚点，形成紧凑的“Shift-Gain-Loss”表示，用于高效检索。
  - **Cognitive Mirror 记忆**：储存的是“扭曲签名-恢复配套”（k_i, c_i）的键值对，而非完整推理轨迹，结构紧凑、支持跨任务复用。
  - **配套检索**：使用加权相似度 S = α₁S_shift + α₂S_gain + α₃S_loss，权重经敏感性分析定为(0.6, 0.2, 0.2)，检索最匹配的恢复配套 c*。
  - **局部恢复**：仅用 c* 修复被扭曲的状态 ŝ_t = R(s_t, c*)，其他状态保持不变，得到修复后的轨迹 R̂。

- ORDDAR在所有四个基准上均优于CoT、Self-Refine、Reflexion、ToT和ProCo，性能提升在CKDQA上最为显著（94.38%准确率），表明在临床分析类任务中局部错误对最终决策影响极大，而局部修复策略尤为有效。
- 相对于全局重新生成推理链，ORDDAR的局部修复方式能够以更高的准确率完成推理，同时保留正确的推理步骤，减少了推理路径的浪费。
- 消融实验证实：扭曲定位（DM）、配套检索（CM）和局部恢复（RM）三者缺一不可，其中扭曲定位和配套检索的性能影响较为突出。
- 嵌入模型实验表明，ORDDAR对语义编码器的选择具有一定的鲁棒性（MPNet、MiniLM和BGE性能基本接近）。
- 定性分析显示，认知镜像的检索结果与检测出的扭曲在语义嵌入空间中接近，说明扭曲签名确实保留了具有判别性的恢复信息。

## 7. 优点

- **视角创新**：将推理问题转化为“认知状态转换”的局部故障检测与修复问题，突破了“全局重新生成”的固有模式。
- **精准定位、局部修复**：仅修复受影响的状态，保留正确推理路径，既节省计算资源又提升稳定性和可解释性。
- **轻量且模型无关**：通过语义编码器和锚点分布计算，不依赖额外的验证大模型，作为独立且高效的中间信号，不会与具体模型耦合。
- **经验复用机制**：Cognitive Mirror以紧凑的“签名-补丁”对形式存储经验，支持跨任务索引，构建了可成长的修复记忆。
- **防数据污染设计**：评估实例在预测前不会插入记忆，避免泄露，提升评估可信度。
- **跨任务通用流程**：核心流程（窗口检测、签名编码、检索、局部恢复）不依赖具体任务，具备通用性。
