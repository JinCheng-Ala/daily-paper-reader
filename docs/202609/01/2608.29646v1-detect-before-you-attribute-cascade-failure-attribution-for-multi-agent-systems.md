## 摘要
基于大型语言模型（LLM）的智能体通过多步推理在解决复杂任务方面展现出巨大潜力，但它们仍然容易受到执行故障的影响。因此，准确的故障归因对于提高智能体可靠性至关重要。现有的基于拓扑和基于频谱的方法利用轨迹结构，但往往忽视细粒度语义，而基于LLM的归因方法能够捕获语义线索，但在长轨迹上却面临长上下文退化问题。为解决这些挑战，我们提出了DUOTRACE，一种即插即用的检测过滤器，用于基于LLM的故障归因。DUOTRACE遵循先检测后归因的范式：它首先检测异常执行，然后向下游基于LLM的归因方法提供聚焦的轨迹证据。为了在智能体轨迹上进行有效的基于VAE的异常检测，DUOTRACE集成了双视图语义-结构节点表示、基于Tree-LSTM的轨迹编码器，以及基于前缀链和LLM的数据增强，以处理异构节点、分层执行结构和有限的故障数据。与六个基于LLM的归因基线进行实验，结果表明DUOTRACE在智能体级和步骤级归因准确率上分别提高了8.7%和7.0%。

## Abstract
Large language model (LLM)-based agents have shown strong potential in solving complex tasks through multi-step reasoning, yet they remain vulnerable to execution failures. Accurate failure attribution is therefore critical for improving agent reliability. Existing topology- and spectrum-based methods exploit trajectory structures but often overlook fine-grained semantics, while LLM-based attribution methods capture semantic cues but suffer from long-context degradation over lengthy trajectories. To address these challenges, we propose DUOTRACE, a plug-and-play detection filter for LLM-based failure attribution. DUOTRACE follows a detect-before-attribute paradigm: it first detects anomalous executions and then supplies focused trajectory evidence to downstream LLM-based attribution methods. For effective VAE-based anomaly detection on agent trajectories, DUOTRACE integrates dual-view semantic-structural node representations, a Tree-LSTM-based trajectory encoder, and prefix-chain- and LLM-based data augmentation to handle heterogeneous nodes, hierarchical execution structures, and limited failure data. Experiments with six LLM-based attribution baselines show that DUOTRACE improves agent-level and step-level attribution accuracy by 8.7% and 7.0%, respectively.

- **核心问题**：由于多步执行架构的复杂性，一个早期阶段不易察觉的细微错误会沿着执行分支逐级传播，最终导致下游任务失败——即所谓的“级联故障”。这类故障延迟显现的特性不仅破坏最终目标，还造成大量计算开销和推理时间浪费。
- **现有方法的不足**：
  - **基于拓扑与频谱的方法**（如 FAMAS、CDC-MAS）能利用轨迹的结构信息（如节点依赖关系），但往往忽略细粒度语义线索，难以为常见的幻觉（hallucination）类故障定位。
  - **基于 LLM 的归因方法**（LLM-as-a-Judge）虽能联合考虑语义与结构信息，但面对长轨迹会出现“lost-in-the-middle”问题（长上下文退化），导致归因准确率随输入长度增加而明显下降（文中图 1 的实验数据清晰展示了该现象）。
- **论文的核心主张**：提出了 **“先检测后归因”（detect-before-attribute）** 的范式——在调用 LLM 判断器之前，先通过异常检测从轨迹中过滤出与故障高度相关的异常节点，将紧凑的故障证据子集交给下游 LLM 进行因果归因。这既能保留语义判别能力，又能缓解长上下文稀释问题、降低计算开销。

## 2. 论文提出的方法论

- **整体架构（DUOTRACE）**：由四个模块构成，即（1）数据增强模块、（2）双视图特征表示模块、（3）轻量级结构 VAE 模块（Tree-LSTM 编码器 + MLP 解码器）、（4）动态加分评分与候选子轨迹蒸馏模块。
- **核心思想**：用 VAE 学习“正常执行轨迹”的流形，将偏离正常模式（重建误差大）的节点视为“异常候选”。异常检测的结果不直接作为因果归因，而是用于“聚焦”下游 LLM 的注意力。
- **关键步骤**：

### 2.1 数据增强
- **LLM Replay 生成**：利用 LLM 在原始任务上下文下重放任务，利用其输出的随机性合成多样且无故障的正常轨迹。
- **前缀链提取**：将完整执行轨迹切分成可变长度的前缀片段，模拟中间操作的时序演变，扩大有效训练空间。
- 文中附录 B 提供了确切的提示词模板（表 13），并采用严格隔离策略防止测试集数据泄露；训练集每条任务独立生成 5 次，形成超过 900 条成功轨迹的增强数据集。

### 2.2 双视图特征表示
- **语义视图（角色感知嵌入）**：用 Sentence Transformer 对智能体身份 ai 和调用算子 oi 编码为稠密向量，拼接形成功能上下文嵌入 [hai ⊕ hoi]，支持跨框架零样本迁移。
- **结构视图（拓扑编码）**：利用邻接矩阵 A 表达父-子调用依赖关系（Ai,j = 1 表示节点 vi 直接调用 vj）。
- 最终的节点特征为语义向量与拓扑信息的融合，确保文本语义与交互拓扑联合建模。

### 2.3 轻量级结构 VAE
- **Tree-LSTM 编码器**：以 Child-Sum Tree-LSTM 遍历层次化执行树，将父节点输入与全部子节点状态融合计算隐藏状态 hi 和单元状态 ci。为防止信息泄漏，输入中明确排除当前节点的实际 token 消耗。
- **潜在空间参数化**：将隐藏状态映射为高斯后验分布参数（μzi 和 log σ²zi），通过重参数化技巧采样潜在变量 zi。其中 μ 编码不变的任务拓扑，σ² 容纳合法的执行变化。
- **多目标 MLP 解码器**：统一 MLP 从 zi 重建双视图输入——包括语义重建（ˆhai、ˆhoi）和执行足迹预测（token 消耗的条件高斯分布参数 μti、log σ²ti）。
- **优化目标**（公式 6）：
  - MSE 项：语义嵌入重建（角色与算子一致性）
  - NLL 项：token 消耗预测的负对数似然（公式 7）
  - KL 散度项：后验分布与先验分布的对齐
  - 联合优化确保只有结构重建失败或语义不一致的轨迹才会被判定为异常。

### 2.4 动态加分点评分
- **Z-score 标准化**：以成功轨迹建立基线（μS, σS），将异常分数标准化为 Z(vi)，追踪执行树扩展过程中的累积异常偏离。
- **早期峰值优先**：Z 分数在早期阶段出现显著突变被视为高优先级的可疑候选。
- **子轨迹蒸馏**：按 Z 分数对全部 N 个节点排序，提取 Top-K（保留约 20%）节点及其拓扑依赖关系，得到紧凑的 Vsub 子轨迹，交由下游 LLM 判断器（如 CORRECT、ECHO）进行最终归因。

## 6. 论文的主要结论与发现

- **总体效果**：DUOTRACE 在六种 LLM 归因基线上，智能体级归因准确率平均提升 **8.7%**，步骤级归因准确率提升 **7.0%**。
- **最佳效果**：DUOTRACE 增强的 CORRECT 模型在 Overall 上取得 69.1% 的 Agent Accuracy 和 49.0% 的 Step Accuracy，超过此前 SOTA（AgenTracer）。在 Handcraft 子集上，增强 Qwen3.5-plus 达到 72.4% 的 Agent Accuracy。
- **普适性**：DUOTRACE 作为即插即用前端，对不同的直接提示式 LLM 和 LLM-as-a-Judge 框架均产生一致的性能提升。例如在 Handcraft 数据集上，Qwen3.5-plus 的 Agent Accuracy 绝对值提升 19.0%，GPT-5 提升 15.5%。
- **效率提升**：Token 消耗最高减少 76%（Qwen3.5-plus：2.12M → 0.50M），推理时间最高缩短 64%（168.6 → 60.6 分钟）；CORRECT 获得 2.5× 加速，ECHO 减少 41% token 和 46% 推理时间。
- **消融关键发现**：
  - 去语义视图导致 Handcraft 子集 R@Top20% 下降 20.69%，去结构视图下降 18.97%——双视图建模缺一不可。
  - 非 Tree 编码器（MLP）一致性最差；Tree-LSTM 优于 GAT 和 Tree-Transformer，验证了树结构归纳偏置的有效性。
  - 动态加分过滤显著优于随机过滤/规则匹配/Top-K 过滤，证明“候选选择质量”而非“单纯缩短轨迹”是提升的关键。
- **鲁棒性与泛化**：面对 20% 语义信息缺失时，DUOTRACE 将平均性能下降从 5.9 个百分点缩减至 2.6 个百分点；对非树执行结构（通过结构展开）也能保持增益；在多原因候选排序（MP-Bench nDCG@5）和跨任务类别零样本设置中均有提升。
- **参数敏感性**：Top-N 保留约 20%~25% 为最佳平衡区间；低于 20% 会丢失根因，高于 30% 会重新触发上下文稀释。

## 7. 方法亮点与优势

- **范式创新**：“先检测后归因”将异常检测从因果归因中解耦，既规避了纯结构方法语义盲区，又缓解了纯 LLM 方法上下文稀释问题。
- **双视图特征表示**：语义（角色感知嵌入）与结构（邻接拓扑）的融合设计兼顾细粒度文本信号与全局依赖关系，对幻觉类故障更敏感，且支持跨框架语义迁移。
- **信息防泄漏设计**：Tree-LSTM 编码器的输入排除节点自身 token 消耗，迫使编码器基于拓扑上下文学习——这一细节设计有效避免了“复制”式欺骗。
- **多目标优化**：语义 MSE + token NLL + KL 散度的联合训练，同时对微观执行不确定性和宏观拓扑结构建模，提高异常检测的判别力。
- **动态评分替代静态阈值**：利用 Z-score 追踪相对偏离而非绝对重建误差，对长步任务和任务间方差更鲁棒。
- **数据增强的巧妙性**：前缀链提取与 LLM 重放模拟双管齐下，缓解正常轨迹稀缺问题；对“任务真值”（GT task）与“诊断真值”（GT diag）的解耦确保无泄漏。
- **工程实用性**：模型轻量（单张 RTX 3060 数小时即可完成训练），推理阶段显著降低 token 开销与延迟，适合实际部署。

## 8. 不足与局限

- **树结构假设依赖**：DUOTRACE 基于树形执行结构，对真实系统中可能存在的共享节点调用、跨分支依赖等非树结构，仍需通过“结构展开”进行间接转换。额外转换可能丢失部分复杂依赖信息（文中表 7 实验虽验证了可行性，但尚未完全贴合真实拓扑）。
- **多原因分解能力有限**：文中明确指出 nDCG 仅衡量候选排名质量而非因果责任分解，即 DUOTRACE 能更好保留多个可疑候选，但如何将这些候选分配给不同失败原因并明确因果责任仍未被解决。
- **LLM 生成数据的多样性风险**：LLM 重放生成的轨迹可能存在风格一致性问题，尽管 VAE 的 KL 正则化在一定程度上缓解了这种人工痕迹，但文本风格同质化仍可能影响语义视图的判别能力。
- **下游 LLM 偏置依赖**：故障归因的最终判断仍依赖下游 LLM 判断器，而 LLM 本身可能存在社会/认知偏差，在特定情境下可能产生有偏归因结果。
- **语义缺失鲁棒性的假设边界**：文中 20% 语义掩码实验假设“执行拓扑保持可观测”，若拓扑信息同样受损（如日志截断），DUOTRACE 的鲁棒性尚不明确。
- **候选保留比例依赖**：性能对 Top-N 保留比例（20%~25%）敏感，实际应用中可能需要针对不同场景调优该超参数。
- **实验场景局限**：所有数据集均来自模拟环境和公开日志，尚未在真实生产环境的多智能体系统中得到验证；且 Handcraft 子集规模较小（58 个实例），统计显著性支撑可能有限。
- **训练数据需求**：即便有数据增强策略，模型仍依赖一定量的正常轨迹。在冷启动、完全缺乏历史日志的场景下，效果可能受限。
