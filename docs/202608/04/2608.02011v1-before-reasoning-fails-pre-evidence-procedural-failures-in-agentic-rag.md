## 摘要
Agentic检索增强生成（RAG）系统可能在测试基于证据的推理之前就失败：智能体可能检索到候选片段，但未检查它们就进行最终化。我们将这种失败模式作为智能体轨迹的程序性属性进行研究，利用保存的工具调用轨迹、检索到的证据、阅读的段落和最终答案，将错误答案分解为证据前纪律失败和黄金阅读后失败。在HotpotQA、2WikiMultiHopQA和MuSiQue上的12,000个配对轨迹中，这两种失败类型在很大程度上是非冗余的：在regex和spaCy实体提取器中，同时触发的比率在[11.2%，13.1%]之间。然后我们评估了Read-Gate，这是一种最小的运行时不变式，要求智能体在搜索之后、最终化之前进行阅读。强制阅读在原本会跳过阅读的轨迹上将LLM-Acc提高了14.9-19.9个百分点，在完整的最小推理单元上提高了3.2-9.4个百分点。额外的诊断表明，更大的隐藏思考预算不一定会增加证据检查。总之，这些结果表明，证据收集应作为轨迹层面的控制问题来评估，与答案侧推理分开。

## Abstract
Agentic retrieval-augmented generation (RAG) systems can fail before evidence-conditioned reasoning is tested: an agent may retrieve candidate snippets but finalize without inspecting them. We study this failure mode as a procedural property of the agent trajectory, decomposing wrong answers into pre-evidence discipline failures and post-gold-read failures using saved tool-call traces, retrieved evidence, read passages, and final answers. Across 12,000 paired trajectories on HotpotQA, 2WikiMultiHopQA, and MuSiQue, the two failure types are largely non-redundant: the both-trigger rate is in [11.2%, 13.1%] across regex and spaCy entity extractors. We then evaluate Read-Gate, a minimal runtime invariant requiring an agent to read after search and before finalization. Forced reading improves LLM-Acc by 14.9-19.9 points on trajectories that would otherwise skip reading and by 3.2-9.4 points on full minimal-reasoning cells. Additional diagnostics show that larger hidden thinking budgets do not necessarily increase evidence inspection. Together, these results indicate that evidence-gathering should be evaluated as a trajectory-level control problem, separately from answer-side reasoning.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：Agentic（智能体式）RAG 系统可能"在基于证据的推理尚未开始之前"就已经失败——即智能体执行了 search、收到了候选片段，**却完全跳过 read 动作，直接给出最终答案**。
- **深层含义**：这种失败并非普通答案推理错误，而是**执行过程中的程序性缺陷**。最终答案的正确率无法反映智能体是否真正按流程检查了证据；如果证据收集本身有缺陷，仅加强推理能力并不足够。
- **作者主张**：证据收集应被视为一个**轨迹级控制问题**，应与答案侧推理分开评估；盲目增加推理努力（思考预算）并不必然提升证据检查行为。
- **核心贡献**：
  1. 提出可操作的轨迹级错误分解框架，区分"纪律失败"（pre-evidence）与"后黄金阅读失败"（post-gold-read）；
  2. 提出 **Read-Gate**——一种最小运行时不变式，强制智能体在搜索后、终结回答前读取证据；
  3. 在 12,000 条配对轨迹上证明两类失败非冗余，证据检查是一条独立于答案推理的控制轴。

## 2. 方法论（核心思想与关键技术细节）

### 2.1 轨迹级错误分解

- 将一条错误轨迹（wrong trajectory）按固定优先级归入互不相交的失败桶：

  **E_wrong = E_disc ∪ E_post ∪ E_retr ∪ E_amb**（优先级依次递减）

- **纪律失败 E_disc（pre-evidence 程序性失败）**：答案错误 + 违反证据检查程序。包括三个可观测子类型：
  - **No-read final**：read 次数为 0 就直接 final 回答；
  - **Snippet-only final**：答案实体只出现在检索片段（snippet）中，从未出现在任何已读 chunk 中；
  - **Low-evidence final**：问题中的命名实体在已读 chunk 中的覆盖率 < 80%（实体覆盖用确定性命名实体匹配启发式计算）。

- **后黄金阅读失败 E_post**：检索成功、智能体确实阅读了至少一个黄金支持 chunk，但最终答案仍错误。
- **检索失败 E_retr**：黄金证据未进入 top-k 检索结果。
- **残余歧义 E_amb**：兜底桶，在鲁棒性分析中占错误案例的 15% 以下。

### 2.2 Read-Gate 运行时不变式

- **机制**：若模型发出 `final` 动作且 `read count = 0`，环境**拒绝该动作**，并追加纠错观察（corrective observation），要求模型先对一个有希望的 chunk 调用 `read` 再作答。
- **设计原则**：不改变模型权重、检索器、索引、评审（judge）、解码温度或推理预算；只改变环境执行规则。
- **额外变体**：论文还实现了更严格的"search 后立即必须 read"（read-after-search）检查，但主实验采用最弱的 read-before-final 规则。

### 2.3 三个可证伪预测（Hypotheses）

- **H1 非冗余**：纪律失败与后黄金阅读失败不应塌缩为同一失败轴。
- **H2 条件收益**：Read-Gate 的准确率增益应与残余纪律错误率呈正相关，而非仅与推理水平相关。
- **H3 可区分响应**：Read-Gate 与推理努力（reasoning effort）应产生不同轨迹特征签名（在 (P_disc, P_post) 平面上）。

### 2.4 统计与分析方法

- 配对 McNemar 检验、配对 bootstrap 置信区间（1,000 次迭代）
- 问题聚类（question-clustered）逻辑回归、多标签二元指示器分析
- 分层标签置换检验（within-cell-stratified label permutation）
- Benjamini–Hochberg FDR 与 Bonferroni 多重检验校正

### 3.1 数据集与 Benchmark

### 3.2 模型与条件

  - `gpt-5-mini`（minimal 推理努力）

- **每数据集 × 条件 = 1,000 道问题**，按问题 ID 配对。

### 3.3 检索与评估

- 检索：混合 BM25 + 稠密检索（0.6B Qwen3-Embedding）倒数排名融合，k=60，TOP-k=5；最大循环 10；温度 0.0。
- 评估指标：**LLM-Acc**（gpt-5-mini judge，温度 0.0，只看问题+黄金答案+预测）；**Contain-Acc** 作为次要指标；附加 Gemini 2.5 Pro 跨评审者复评（n=450，κ=0.924）。

### 3.4 主要消融与对照组

1. **三臂机制消融**（每数据集配对 n=1,000）：无 Read-Gate / Read-Gate / ctx-inject（把同样的 rank-1 chunk 文本以 user 角色观察注入，但不产生 read 工具调用）。
2. **四臂通道 vs 动作探针**（MuSiQue，n=500）：无 Read-Gate / user-role 注入 / tool-role 注入 / Read-Gate。
3. **仅提示控制**（strict prompt）：只修改系统提示，不使用环境门控。
4. **门族探针**（n=100）：Read-Gate / +snippet / +low-evidence / full 变体。
5. **中等推理边界消融**（n=100）：Read-Gate 在 medium 推理下的效果。
6. **跨家族细胞**（Qwen2.5，n=200/cell）。
