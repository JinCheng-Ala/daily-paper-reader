## 摘要
随着基于大型语言模型（LLM）的多智能体系统能力日益增强，在不确定性下协调智能体成为一个基本挑战。现有编排策略通常依赖固定的交互模式，且往往缺乏评估中间推理步骤可靠性的机制，导致错误和幻觉在系统中传播。本文提出了一种语义不确定性引导的编排方法，HASSUM，作为多智能体系统中不确定性感知协调的通用框架。该方法使用语义熵和语义密度来估计不确定性，这些指标在答案语义层面而非输出概率层面衡量信任度。这些信号支持自适应编排决策，包括输出验证、选择性重新提示、额外审议以及置信度感知的响应选择。由于该方法独立于任何特定的智能体架构，它可以集成到广泛的分层和协作式多智能体系统中。评估展示了在分层智能体框架中的实现，并在StrategyQA、JailbreakBench和TruthfulQA基准上进行了评估。在需要复杂推理且易于产生歧义或幻觉的任务中，不确定性引导的编排比不考虑不确定性的协调产生更可靠的结果。语义熵和语义密度联合使用优于单独使用任一指标。针对不同阈值和模型规模的消融实验表明，两者都会影响语义指标的有效性。结果表明，语义不确定性是提高智能体AI系统鲁棒性和可信度的一种实用且通用的信号。

## Abstract
As large language model (LLM)-based multi-agent systems become increasingly capable, coordinating agents under uncertainty becomes a fundamental challenge. Existing orchestration strategies typically rely on fixed interaction patterns and often lack mechanisms for assessing the reliability of intermediate reasoning steps, allowing errors and hallucinations to propagate through the system. This paper introduces a semantic-uncertainty-guided orchestration approach, HASSUM as a general framework for uncertainty-aware coordination in multi-agent systems. The method estimates uncertainty using semantic entropy and semantic density, which measure trust at the level of answer semantics rather than output probabilities. These signals enable adaptive orchestration decisions, including output verification, selective reprompting, additional deliberation, and confidence-aware response selection. Because the approach operates independently of any particular agent architecture, it can be integrated into a broad range of hierarchical and collaborative multi-agent systems. The evaluations demonstrate an implementation within a hierarchical agent framework and evaluate it on StrategyQA, JailbreakBench, and TruthfulQA benchmarks. Across tasks that require complex reasoning and are prone to ambiguity or hallucinations, uncertainty-guided orchestration yields more reliable outcomes than uncertainty-unaware coordination. Semantic entropy and semantic density in tandem outperformed either metric alone. Ablations testing different thresholds and model sizes demonstrated that both influence the effectiveness of semantic metrics. The results suggest that semantic uncertainty is a practical and general-purpose signal for improving robustness and trustworthiness in agentic AI systems.

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：将语义不确定性度量嵌入分层多智能体系统的编排循环中，使中央编排器（CEO 智能体）能够根据中间结果的语义可靠性，动态决定是否重新提示、更换 worker、并行委派多个 worker，或直接接受输出并合成最终答案。
- **基础框架**：基于 HASHIRU——一种 CEO 智能体将任务分解为子任务并分配给专门 worker 的分层 MAS；CEO 负责 worker 选择、重新提示与委派，语义不确定性信号用于增强这些本已支持的决策。
- **两种不确定性指标**：
  - **语义熵（Semantic Entropy）**：通过对采样响应进行成对蕴含分组，将响应聚类为语义等价类，再计算聚类分布上的香农熵，用于检测语义层面的**矛盾与分歧**。公式：H = −Σ p(Ci) log p(Ci)。
  - **语义密度（Semantic Density）**：将响应嵌入连续向量空间（使用 all-MiniLM-L6-v2），通过核方法（Epanechnikov 核）估计响应在嵌入空间的集中程度，用于检测**模糊与不精确**（即使响应方向一致但缺乏精确性）。公式：D = (1/N²) ΣΣ K(φ(yi), φ(yj))。
- **两种指标互补性**：熵对矛盾敏感、密度对模糊敏感，结构性互补，联合使用可覆盖对方盲区。
- **编排流程**：CEO 收到查询 → 分解 → 分配 worker → worker 生成候选响应 → CEO 对额外采样计算语义密度/熵并与预设阈值比较（如 density ≥ 0.8, entropy ≤ 1.1）→ 未达标则触发重提示、换 worker 或多 worker 并行 → 循环至通过或达到轮次上限 → 合成最终答案。
- **具体实现细节**：每个 worker 响应额外采样4次（温度0.85）用于计算指标；对 CEO 直接回答的场景增设了显式多智能体调用以促进分层行为；添加了 JSONL 轨迹日志与重提示上限以防止无限循环；特意解除了 HASHIRU 的资源预算约束以观察不确定性信号对决策的纯影响。

## 6. 论文的主要结论与发现

- **主要基准上的显著提升**：语义不确定性感知编排一致优于无感知编排。JailbreakBench（25%→61%）和 TruthfulQA（19%→41%）上准确率翻倍以上，置信区间无重叠；StrategyQA（70%→78%）也有八个百分点提升。
- **增益幅度与基线可靠性负相关**：基线越弱，不确定性引导带来的改善越大，说明语义不确定性主要捕获可恢复的不稳定类失效。
- **双指标联合优于单指标**：语义熵与语义密度结合使用的表现超过任一单独使用；单独使用任一指标甚至不如完全不用。原因在于两种指标各自的盲区恰好是对方的检测范围（密度单独太宽松、熵单独太保守）。
- **边界条件（核心发现）**：语义不确定性对**歧义和语义不稳定驱动**的失效（如模糊、回避式回答、幻觉倾向任务）最有效；当失败源于**事实性缺口、检索失败、逻辑错误**时收益有限甚至产生负效果（MuSiQue -10pp，HotpotQA -14pp；IFBench 有 +8pp 的例外）。
- **模型能力消融发现**：尽管 GPT-5.4 产生远高于本地模型的语义密度（0.957 vs 0.887）和远低于本地模型的语义熵（0.058 vs 0.949），最终系统准确率相同（78%），说明 HASSUM 的干预机制能够补偿较弱的 worker 模型。
- **轨迹分析发现**：语义指标可靠识别不稳定响应，但恢复动作必须与实际错误源匹配才能将检测转化为正确纠正；错误事实被自信且一致地陈述时，两种指标都无法捕捉。

## 8. 不足与局限

- **实验规模受限**：受计算资源约束（单张 RTX 3060 的个人机器），基准仅使用 100–500 题的子集而非完整数据集；多数配置只运行一次，缺乏多随机种子平均，对效应量的估计稳健性有限。
- **恢复策略单一**：当语义指标正确触发关注后，CEO 的恢复动作有时只是对同一 worker 进行轻微措辞变化的重复重新提示，而非更换 worker 或改变推理策略；在 MMLU 的一个轨迹中，反复重提示消耗了全部轮次预算却未回到原始问题。
- **固定阈值的问题**：实验使用固定阈值（density 0.8, entropy 1.1），但 worker 模型能力不同时相同阈值的意义不同；自适应或任务/模型特定的阈值调整未被探索。
- **scope 基准效果不稳定**：在多跳 QA 上产生显著负效果（额外推理主要重访同一错误轨迹），说明该方法并非通用增益，需要在部署前判断任务失效模式类型。
- **资源预算被排除**：论文主动解除了 HASHIRU 的资源预算系统以观察纯不确定性效果，但真实部署中计算成本与收益的权衡是关键问题，这一交互留待未来工作。
- **指标自身的盲区**：对信心十足但事实错误且内部一致的响应，语义熵和语义密度均无法捕捉；不确定性对于可恢复性是必要但不充分条件——检测不稳定不等于能够纠正错误。
