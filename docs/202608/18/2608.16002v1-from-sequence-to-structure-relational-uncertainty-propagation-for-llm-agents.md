## 摘要
可靠的不确定性量化（UQ）对于在复杂交互环境中部署大型语言模型（LLM）智能体至关重要。现有的UQ方法主要依赖局部信号，如词元概率、预测熵或逐步置信度，因此忽略了错误在执行轨迹中累积的长程依赖关系。这可能导致它们无法识别那些原因发生在最终答案之前若干推理或交互步骤的智能体失败。我们提出RUPA（面向智能体的关系不确定性传播），一种面向LLM智能体的轨迹级UQ框架。RUPA将执行历史表示为有向轨迹图，其中推理状态、工具交互和环境反馈作为节点，通过时间和语义依赖边连接。然后，它在该图上传播不确定性，以捕获执行风险如何在交互步骤间累积和转移。传播信号与轨迹级行为特征和目标一致性信息相结合，为整个智能体轨迹生成置信度估计。我们在代表性智能体基准测试（包括τ-2、Terminal-Bench-2和GAIA）上，使用来自多个模型家族的6个开源LLM评估了RUPA。实验结果表明，RUPA通过提供更准确的不确定性估计、实现更早的故障检测，并改进各种智能体任务中的不确定性引导的智能体执行，持续优于现有UQ方法。这些结果表明，显式建模关系依赖对于长视野LLM智能体的可靠UQ至关重要，为可信的智能体执行提供了实用基础。

## Abstract
Reliable uncertainty quantification (UQ) is essential for deploying large language model (LLM) agents in complex interactive environments. Existing UQ methods largely rely on local signals, such as token probabilities, predictive entropy, or per-step confidence, and therefore overlook the long-range dependencies through which errors accumulate across an execution trajectory. As a result, they may fail to identify agent failures whose causes originate several reasoning or interaction steps before the final answer. We propose RUPA (Relational Uncertainty Propagation for Agents), a trajectory-level UQ framework for LLM agents. RUPA represents an execution history as a directed trajectory graph in which reasoning states, tool interactions, and environment feedback are nodes connected by temporal and semantic dependency edges. It then propagates uncertainty over this graph to capture how execution risk accumulates and transfers across interaction steps. The propagated signal is combined with trajectory-level behavioral features and goal-alignment information to produce a confidence estimate for the full agent trajectory. We evaluate RUPA on representative agent benchmarks, including $τ$-2, Terminal-Bench-2, and GAIA, using 6 open-source LLMs spanning multiple model families. Experimental results show that RUPA consistently outperforms existing UQ methods by providing more accurate uncertainty estimates, enabling earlier failure detection, and improving uncertainty-guided agent execution across diverse agent tasks. These results demonstrate that explicitly modeling relational dependency is crucial to reliable UQ for long-horizon LLM agents, providing a practical foundation for trustworthy agent execution.

## 2. 方法论：RUPA框架

### 总体思路
RUPA（Relational Uncertainty Propagation for Agents）将智能体执行轨迹转化为有向关系图，在图上进行不确定性传播，捕获执行风险在推理、工具使用和环境交互中的累积与转移，最终结合局部不确定性输出轨迹级置信度估计。

### 步骤一：关系轨迹图构建（Relational Trajectory Graph Construction）
- 将每个执行前缀表示为有向图 **G = (V, E)**，节点对应执行事件（用户指令、助手推理/动作、工具调用、环境观察）。
- 在有限历史上下文内构建依赖边，考虑**七种关系类型**：
  - **Sequential（顺序）**：紧邻的前一个执行步骤
  - **Latest（最新）**：最近的环境或用户指令
  - **Repetition（重复）**：推理模式或工具使用高度相似的行动
  - **Progression（推进）**：扩展已有解步骤的推理
  - **Parallel（并行）**：同一任务上下文下的备选推理分支
  - **Feedback（反馈）**：对环境观察的反馈，指示执行失败或不稳定输出
  - **Goal Alignment（目标对齐）**：当前推理步骤与原始任务目标之间的语义依赖

### 步骤二：关系感知的不确定性传播（Relation-aware Uncertainty Propagation）
- **局部不确定性（Uₜ）**：对助手节点，使用预测熵；对环境节点，从可观察的交互信号（执行失败、空工具响应、冲突反馈）估计。
- **边权计算公式**：  
  **wᵢₜ = ρ₍τᵢₜ₎ · r̃ᵢₜ · δ^(age(i,t)−1)**  
  其中δ为时间衰减因子，ρ为关系类型的可靠性系数，r̃为关系强度。结构化重要的历史依赖获得更大影响，而过时的执行状态被逐渐折扣。

- **目标对齐分数**：  
  **Qᵢₜ = 1 − S(yₜ, x)**  
  其中S是相似度函数，衡量当前步骤与原始目标的语义对齐程度。

- **传播不确定性聚合**：  
  **Gₜ = Σᵢ₌ₙ₍ₜ₎ wᵢₜ(Pᵢ + Qᵢₜ) / (Σᵢ₌ₙ₍ₜ₎ wᵢₜ + ε)**  
  其中Pᵢ是历史节点i存储的传播不确定性，N(t)是与当前步骤连接的历史节点集合。

- **动量机制与历史不确定性**：  
  **mₜ = Σₖ₌ₜ γ^(t−k)Pₖ / (Σₖ₌ₜ γ^(t−k) + ε)**  
  **Hₜ = η_g·Gₜ + η_m·mₜ**  
  动量项保留长程执行趋势，使早期执行失败能够持续影响后续推理。

- **最终风险估计**：  
  **Rₜ = λᵤ·Uₜ + λₕ·Hₜ**  
  综合当前生成的固有不确定性和历史累积的结构不确定性。对完整轨迹，聚合各步骤的不确定性得分得到轨迹级估计，得分越高表示任务失败概率越大。

### 关键设计特点
- 边权重由关系类型的统计重要性自动确定（基于未标注轨迹上的变异系数校准），使不确定性优先沿有影响力的执行路径传播。
- 避免在构图阶段使用未来结果或最终验证器标签，实现结果盲（outcome-blind）的校准。

## 6. 主要结论与发现

1. **传统UQ方法在长时程智能体任务上基本失效**：熵和序列概率方法的AUROC接近随机猜测，因为它们只利用当前生成的置信度，忽略了历史推理和环境交互的依赖关系。
2. **顺序性智能体UQ方法也不充分**：SAUP、Tracer、UProp等通过纳入顺序执行信息有所改进，但未捕获关系结构中的风险传播，性能仍有明显差距。
3. **RUPA一致最优**：在所有6个模型上，RUPA取得最高的平均AUROC、AUPRC和F1。例如，Qwen3.5-27B上AUROC从0.608提升至0.656，MiniMax-M2.7从0.694提升至0.718，Gemma4-31B从0.842提升至0.861。
4. **RUPA支持更早的失败检测**：前缀分析表明，在仅观察到轨迹的一小部分时RUPA的优势尤为显著，说明传播的不确定性信号在早期就已出现。
5. **不确定性估计可转化为实际性能提升**：在不确定性引导的采样框架下，RUPA在Terminal-Bench-2上使Qwen3.5-27B准确率从0.105（随机选择）提升至0.213。
6. **图建模提供传统置信度之外的互补信号**：熵匹配分析显示，在熵值几乎相同的情况下，RUPA的AUROC仍能达到约0.85，表明关系结构中的异常依赖模式是独立于局部置信度的信息源。
7. **消融验证核心设计**：去除图建模和不确定性传播均造成显著性能下降，随机图拓扑的效果与去除图建模类似，证明收益来自有意义的依赖结构而非简单的图特征增广。
