## 摘要
与外部资源集成的LLM智能体获得了复杂任务能力，但统一的自然语言上下文通道使其易受注入攻击：不可信的外部数据可能在LLM推理过程中被动态解析为行为引导指令，从而颠覆智能体的决策。现有防御措施侧重于在输入/输出层面进行静态检测或隔离恶意内容，对于检测模型推理过程中出现的此类动态诱导仍不足够。我们提出Attnlocate，一种用于细粒度定位真正影响工具调用决策的上下文片段（即行为引导指令）的运行时框架。Attnlocate将此定位问题转化为目标检测任务，旨在检测注意力矩阵中由行为引导指令引发的独特激活痕迹。具体地，我们设计了一种多头、多层注意力聚合方案，以构建适合目标检测的令牌级特征空间。然后，部署配备无锚检测头的一维U-Net来检测这些片段。最后，基于检测到的行为引导片段来源提供方的权威性，Attnlocate动态裁决恶意调用尝试。我们在来自五个LLM家族的十种智能体配置上评估了Attnlocate，涵盖间接提示注入和工具中毒场景。Attnlocate实现了平均IoU为0.743，平均AUROC为0.956，在0.067假阳性率下真阳性率为0.934。它还能有效迁移到未见模型，并支持无需重新训练即可调整权威策略。

## Abstract
LLM agents integrated with external resources gain complex task capabilities, yet the unified natural-language context channel makes them vulnerable to injection attacks: untrusted external data may be dynamically parsed as behavior-guiding instructions during LLM inference, thereby subverting the agent's decision. Existing defenses focus on static detection or isolation of malicious content at the input/output level, remains insufficient for detecting such dynamic inducements that arise during model reasoning. We propose Attnlocate, a runtime framework for fine-grained localization of context spans that genuinely influence tool-calling decisions, i.e., behavior-guiding instructions. Attnlocate casts this localization problem as an object detection task, aiming to detect the distinctive activation traces induced by behavior-guiding instructions within the attention matrix. Specifically, we design a multi-head, multi-layer attention aggregation scheme to construct a token-level feature space tailored for object detection. Then, a 1-D U-Net equipped with an anchor-free detection head is deployed to detect these spans. Finally, based on the authority of the provider from which the detected behavior-guiding spans originate, Attnlocate dynamically adjudicates malicious invocation attempts. We evaluate Attnlocate across ten agent configurations from five LLM families, covering scenarios involving indirect prompt injection and tool poisoning. Attnlocate achieves a mean IoU of 0.743, an average AUROC of 0.956, and a 0.934 true-positive rate at 0.067 false-positive rate. It also transfers effectively across unseen models and supports authority policy adaptation without retraining.

## 2. 方法论：核心思想、关键技术细节与流程

- **核心思想**：在 LLM 生成决策时，注意力矩阵中会留下“行为引导指令”特有的激活痕迹——这些痕迹与普通的上下文显著性、attention sink 不同。AttnLocate 将识别行为引导指令的问题**重构为目标检测任务**，检测注意力矩阵中的高激活区域，并推断其区间边界。

- **整体流程（三阶段）**：
  1. **注意力聚合（Attention Aggregation）**
     - 对多头注意力按层取平均：`Ā^(l) = (1/H) Σ_h A^(l,h)`；
     - 使用**高斯层权重**聚合各层：`w_l = exp(−(l−μ)²/(2σ²)) / Σ_r exp(−(r−μ)²/(2σ²))`，默认 `μ ≈ 2L/3`、`σ = 2`，强调中上层任务相关信号；
     - **决策条件切片**：仅保留与最终决策 token 相关的注意力权重 `A_y = A[P(y), P(C_external)]`，忽略中间推理 token，从而专注于最终工具调用决策；
     - **特征提取**：对每个上下文位置提取均值、最大值、标准差、以及可学习的注意力池化特征，构成 token 级特征序列 Z。
  2. **指令定位（Instruction Localization）**
     - 采用**1-D U-Net**作为骨干网络，编码器逐步降采样捕获长程依赖，解码器通过跳跃连接恢复 token 级分辨率，精确定位边界；
     - 使用**anchor-free 检测头**（基于 FCOS）：每个位置预测 objectness logit `o_i`、左右边界偏移 `(l_i, r_i)` 和 centerness `c_i`；同时一个样本级头输出二分类 logit `s`，判定当前决策是否依赖任何行为引导片段；
     - 推断时只输出一个高置信区间：`i^* = argmax_i σ(o_i)σ(c_i)`，若 `σ(s) < δ` 则输出空集；
     - **Sink-aware 正则化（关键创新）**：对高注意力但背景远高于均匀水平的 token（即 attention sink 类噪声）加大训练权重 `α_sink`，避免将其误检为指令。
  3. **未授权行为裁决（Unauthorized Behavior Adjudication）**
     - **来源解析**：从运行时上下文中的结构化分隔符/来源标注构建 provenance map Γ_t，将局部化跨度映射到具体提供者；
     - **权威仲裁**：依据可配置策略 Π 为各提供者分配权威等级；若 `Π(ρ(τ̂_t)) < R_y`（当前执行所需最小权威）且局部化跨度非空，则判定为恶意调用；
     - 每个告警都包含局部化跨度、来源提供者、违反的权威要求，因此**可审计**。

- **训练目标**：`J = J_focal + λ_giou·J_giou + λ_cls·J_bce`，融合焦点损失、一维 GIoU 损失和样本级二分类损失。

## 6. 主要结论与发现

- **AttnLocate 具有强大的定位能力**：在全部配置上 mIoU 达到 0.692~0.858，平均 0.743；在思维模式下定位效果显著提升（Qwen3 上约提升 5.4%）。
- **裁决能力优于现有方案**：平均 AUROC 0.956，TPR 0.934（FPR 0.067）；与静态扫描、行为审计、归因方法对比，AttnLocate 在 TPR 和 FPR 上全面领先（例如 Phi-4† 上 TPR 0.947，FPR 0.070，远优于 TracLLM 的 0.873/0.149）。
- **跨模型迁移有效**：从 Qwen3-8B† 迁移到未见模型（如 DeepSeek-R1-Qwen-14B†、Phi-4†）仍能保持 mIoU 0.736/0.658、AUROC 0.921/0.859，证明检测器学习到的注意力拓扑特征具有一定的通用性。
- **输入长度与性能负相关**：上下文长度从 ≤256 增加到 >2048 时，mIoU 从 0.811 降至 0.695，TPR 从 0.972 降至 0.857，同时 FPR 从 0.071 降至 0.016（信号被稀释但虚警也减少）。
- **层加权与 sink 正则化至关重要**：μ = 2L/3 的加权中心在 mIoU 和 TPR/FPR 之间取得最佳平衡；β = 10 在不显著损失 TPR 的情况下将 FPR 从 0.417 降至 0.056。
- **权威策略可平滑调整**：从仅信任系统/用户到逐步允许工具/结果来源，TPR 高于 0.909、FPR 低于 0.086，表明无需重新训练即可适配不同部署策略。

## 7. 优点

- **问题定义新颖且准确**：将“未授权行为”明确定义为“行为引导指令的来源权威不足”，而非单纯依赖恶意文本特征，这更贴近 LLM 被动态诱导的本质。
- **方法论精巧**：将注意力矩阵上的指令识别转化为目标检测任务，结合 1-D U-Net 和 anchor-free 检测头，天然适应不确定边界和可变长度；sink-aware 正则化针对注意力噪声，显著降低误报。
- **可解释性与可审计性**：每个告警都返回局部化跨度、来源提供者和被违反的权威策略，而不是简单输出“恶意/良性”，为安全运维提供可行证据。
- **政策自适应**：权威仲裁与定位解耦，允许部署方灵活配置信任层级而无需重新训练检测模型。
- **跨模型泛化能力强**：在未见过的模型上仍保持较好的定位和裁决效果，说明检测的不是模型特定的表面特征。
- **对比基线全面**：覆盖了静态扫描、行为审计、归因分析三大主流范式，且指标选择涵盖了定位质量和裁决质量两个维度。

## 8. 不足与局限

- **白盒依赖**：AttnLocate 需要从底层模型提取注意力矩阵，适用于自托管或可访问内部激活的平台；对于闭源 API 模型（如 GPT-4o、Claude 系列）无法直接部署。
- **未评估对抗性攻击者**：本文假设攻击者仅控制外部内容，但未考虑“攻击者被告知存在注意力监测后，会刻意修改注入文本以降低高激活特征”的对抗场景，因此安全边界可能过高估计。
- **长上下文鲁棒性有限**：当上下文长度超过 2048 token 时，mIoU 和 TPR 显著下降，而现代 Agent 往往需要处理更长的工具结果和多轮交互；论文没有给出缓解方案。
- **实验中的小不一致**：摘要称“五个 LLM 家族”，正文却呈现了六个家族（加上 Gemma），说明稿件可能经过多次修改，表述不够严谨。
- **跨模型迁移实验设计有限**：仅使用单一来源模型训练，未测试多源联合训练或不同目标模型组合，迁移结论的普遍性有待加强。
- **部署代价未量化**：未有报告内存占用、每秒推理次数、额外时延等工程指标；在延迟敏感型 Agent 系统中，运行额外的 1-D U-Net 检测头会引入多少开销尚不明确。
- **基准数据集的局限性**：MCPTox 和 InjecAgent 虽然代表两类主流攻击，但现实世界中的注入方式更加多样（如多轮对话注入、编码混淆、多阶段指令等），论文未覆盖这些变体。
