## 摘要
基于LLM的智能体执行多步任务，但其行为结构仍然不透明：长而非结构化的轨迹难以进行部署所需的安全审计和运行时监控。现有方法要么按单条轨迹处理，要么只关注成功情况，因此错过了连接下一步预测和失败预测的跨运行拓扑结构。为了恢复这种共享结构，我们将整个轨迹语料库压缩为一个紧凑的有限状态机（FSM），作为LLM智能体原本不可预测行为的结构基底。在十二个公共数据集上，FSM都很紧凑（7-43个状态），回放留出数据的拟合度≥0.997，且不同划分下的拓扑几乎相同，构建时间仅为毫秒级。这一基底同时解决了两个预测目标。对于下一步预测，FSM状态上下文在每个真实值匹配的数据集上都优于智能体工作流记忆（Agent Workflow Memory）。对于失败预测，每个状态的行为特征在留出数据上的AUROC高达0.94，在线监控器能从部分轨迹中将失败运行排在通过运行之上，从而在任务完成前很早就触发提前停止。因此，行为拓扑似乎更多由部署框架而非LLM塑造，这为安全审计和运行时监控提供了一种与模型无关的结构原语。

## Abstract
LLM-based agents execute multi-step tasks, but their behavioral structure remains opaque: long unstructured traces resist the safety auditing and runtime monitoring that deployment requires. Existing approaches operate per-trace or success-only, so they miss the cross-run topology that links next-step and failure prediction. To recover that shared structure, we collapse an entire trace corpus into a single, compact finite-state machine (FSM) that serves as a structural substrate for the otherwise unpredictable behavior of LLM agents. Across twelve public datasets, the FSMs are compact (7-43 states), replay held-out data at >=0.997 fitness with near-identical topology across splits, and build in milliseconds. This substrate addresses both prediction goals. For next-step prediction, FSM-state context outperforms Agent Workflow Memory on every ground-truth-matched dataset. For failure prediction, per-state behavioral features reach held-out AUROC up to 0.94, and an online monitor ranks failing runs above passing ones from a partial trace, triggering early stopping well before completion. Behavioral topology thus appears shaped more by the deployment harness than by the LLM, providing a model-agnostic structural primitive for safety auditing and runtime monitoring.

## 1. 核心问题与整体含义（研究动机与背景）

- 论文聚焦于 **LLM 智能体多步任务执行的可审计性与可监控性问题**。随着智能体在代码开发、网页导航、桌面操作、客户服务等场景中承担更长的推理链和更广的动作空间，其行为轨迹（trace）变得冗长且无结构化，难以直接进行安全审计或运行时监控。
- 现有行为分析方法主要存在两类局限：一是**逐条轨迹分析**（per-trace），无法揭示跨运行共有的行为拓扑；二是**仅关注成功轨迹**（success-only），忽略了失败样本中蕴含的结构化偏差。这导致下一步预测与失败预测之间缺乏统一的“共享结构”支撑。
- 论文的核心主张是：**LLM 智能体的行为虽然看似复杂，但实际上由一组有限的工具/动作生成（活动字母表仅 6–42 个符号），因此可以用一个紧凑的有限状态机（FSM）作为行为基底**，同时支撑工作流记忆、下一步预测、失败预测和运行时监控。该结构更多反映“部署框架”（系统提示、工具集、任务分布）而非具体 LLM，因此具有模型无关性。

## 2. 方法论：核心思想、关键技术与算法流程

- **核心思想**：从整个轨迹语料中逆向重建一个解释观测行为的 FSM。由于智能体行为字母表受限，FSM 可以做到非常紧凑（7–43 个状态），从而每个状态能聚合足够多的观测，使下游估计统计良态。
- **活动提取函数 φ**：
  - 按优先级使用三种规则：工具调用名（tool call function name）→ `[ACTION]` 标签 → 代码块首命令语义类别。
  - 若无匹配，则回退为 `角色:内容类型`（如 `assistant:text`）。
  - 论文验证了默认提取粒度在 12 个数据集上能保持拟合度 ≥0.999，并对粗细粒度不敏感。
- **FSM 构建三步**（算法 A.1）：
  1. **前缀树（Trie）**：将所有活动序列插入前缀树，每个唯一前缀为一个状态，得到完美训练拟合但状态数为 O(ΣᵢTᵢ)。
  2. **按最后活动合并**：通过“最后活动右同余” `q ∼ q′ ⇔ κ(q) = κ(q′)` 将 trie 状态合并为 `|A| + 1` 个类，并汇聚转移计数，得到确定性直接跟随自动机（directly-follows automaton）。
  3. **罕见转移过滤**：删除仅在语料中出现一次且不是源状态唯一续接的转移，以去除一次性偏离行为。这是唯一可能损失拟合度的步骤，论文通过回放拟合度直接量化该损失。
- **理论保证**：
  - **定理 2（保真性）**：最后活动合并不降低训练拟合度。
  - **定理 3（确定性与紧凑性）**：合并后状态数为 `|A|+1`，且构造是语料的确定性函数，对固定语料唯一。
  - **命题 5（收敛性）**：在 i.i.d. 轨迹假设下，样本数 N ≥ (1/p_min) ln(r/δ) 时，以概率 ≥1-δ 恢复总体直接跟随自动机。
- **预测方法**：
  - **下一步预测**：用 FSM 当前状态 q_t 估计 `P(a_t|q_t)`（加平滑），也可通过 PPM 绝对折扣整合高阶上下文。
  - **失败预测**：回放轨迹后提取每状态访问特征（访问频率、消息长度、错误率、时间特征）和五类 FSM 交叉熵异常特征（轨迹 CE、最大惊讶、半程漂移、最小转移概率、高惊讶率），用 L1 正则化特征选择 + 梯度提升分类器。
  - **在线监控**：使用循环率（cycle-rate）阈值和最小唯一状态数规则，无需训练 ML 模型，仅需 FSM 回放。

## 6. 主要结论与发现

- **紧凑性与保真性**：FSM 仅 7–43 个状态，测试回放拟合度 ≥0.997，压缩率（vs RPNI）达 15–3036 倍；Alergia 是最近竞争者，但状态数多 1–6 倍。
- **下一步预测**：FSM 状态条件（一阶 Markov）平均 CE 为 0.93 bits，比 Unigram 降低 62%；受控消融显示 FSM 状态提供 +0.155 bits（21%）增益；FSM-LR（K=7）达到最优平均 CE 0.729。
- **工作流记忆**：FSM 作为 LLM 上下文在 8 个数据集上全部胜过 AWM，增益 +0.8~+25.3pp（6/8 统计显著 p<10⁻⁸）。
- **失败预测**：每状态特征在留出数据上 AUROC 最高 0.941（tau2-tel），提升 MLP/GRU/Transformer 基线在 20/21 个数据-架构组合上的表现。
- **在线监控**：组合规则在 SWE-agent 上以 32% 平均完成度触发早停，F1=0.904；高精度操作点可达 100% 精确率（零误报）。
- **拓扑由部署框架决定**：单一 FSM 在 4 个 LLM 的轨迹上均达到 1.000 拟合度；跨模型失败预测转移 AUROC 均值 0.786（vs 自测 0.877），表明行为结构主要来自系统而非模型。
