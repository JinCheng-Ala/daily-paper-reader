## 摘要
基于LLM的多智能体系统（MAS）通过角色专业化智能体之间的通信解决复杂任务。然而，智能体间的依赖关系引入了超出孤立智能体故障的可靠性风险。例如，中间消息中的错误可能被下游智能体继承并放大。现有不确定性量化（UQ）方法主要针对孤立响应或单智能体推理，因此无法捕捉MAS中的不确定性传播。为此，我们提出PropUQ-MAS，一种错误传播感知的UQ框架，将MAS执行表示为通信结构图，并通过结合局部不确定性与从上游消息继承的不确定性来估计每个步骤的可靠性。大量实验表明，PropUQ-MAS持续改善了MAS中的UQ，在AUROC上平均相对提升+6.10%，在PRR上平均相对提升+47.58%。

## Abstract
LLM-based multi-agent systems (MAS) solve complex tasks through communication among role-specialized agents. However, inter-agent dependencies introduce reliability risks beyond isolated agent failures. For instance, errors in intermediate messages could be inherited and amplified by downstream agents. Existing uncertainty quantification (UQ) methods mainly target isolated responses or single-agent reasoning, and therefore fail to capture uncertainty propagation in MAS. To this end, we propose PropUQ-MAS, an error propagation-aware UQ framework that represents MAS execution as a communication-structured graph and estimates each step's reliability by combining local uncertainty with uncertainty inherited from upstream messages. Extensive experiments demonstrate that PropUQ-MAS consistently improves UQ in MAS, with average relative gains of +6.10% in AUROC and +47.58% in PRR.

# 论文详解：PropUQ-MAS 用于 LLM 多智能体系统的传播感知不确定性量化

## 1. 核心问题与整体含义

论文针对基于大语言模型（LLM）的多智能体系统（MAS）在复杂任务协作中的可靠性风险展开研究。MAS 依赖角色分工与多步通信协作，但智能体之间的依赖关系会引入一种关键的系统级风险：**错误沿消息传播并在下游被继承/放大**。例如，某个中间智能体产生的错误推理若被下游智能体当作有效上下文接受，则最终输出即使“局部看起来很自信”，实际上仍可能不可靠。

现有不确定性量化（UQ）方法主要针对：
- 孤立响应（如 token 概率、自评估、语义一致性）；
- 单智能体多步推理轨迹（如 agentic UQ）；
- 轨迹级整体不确定性（如 MATU，需要多次采样执行）。

这些都未能显式建模 MAS 中**跨智能体通信边上的不确定性传播**，且 MATU 这类后验设计无法支持实时、节点级在线监控。因此，论文提出 **PropUQ-MAS**，一种传播感知的 UQ 框架，将 MAS 执行展开为通信有向无环图（DAG），结合局部不确定性与上游传播不确定性，为每个中间输出提供实时的可靠度信号。

## 2. 方法论

### 核心思想
- 将 MAS 执行轨迹表示为 DAG：节点 $v=(i,t)$ 表示智能体 $i$ 在第 $t$ 步的输出，边 $(p,v)$ 表示节点 $v$ 的生成条件依赖于节点 $p$ 的信息。
- 每个节点的总不确定性 $r_v = \Pr(E_v=1)$ 被分解为**局部错误**（$I_v$）与**父节点传播的污染事件**（$Z_{pv}$）两部分。
- 通过两个条件独立性假设（边间污染独立、局部错误与传入污染独立），推导出递归传播公式：

$$r_v = 1 - (1-u_v)\prod_{p \in \mathrm{Pa}(v)} (1-\alpha_{pv} r_p)$$

其中：
- $u_v$ 为局部不确定性，由现成单智能体 UQ 方法（如 MSP、Verbalized）估计；
- $\alpha_{pv}$ 表示父节点 $p$ 在出错时被 $v$ “接受”的边级传播强度；
- $r_p$ 为父节点的传播感知不确定性。

### 关键实现细节
- **传播模式**：将每条通信边建模为“接受 (A)”或“批判 (C)”两类模式。接受错误父信息会形成污染事件，批判则不会直接产生错误。
- **在线代理**：真实错误条件参数 $\alpha_{pv}$ 在线不可观察，因此用智能体自报的采纳分数 $\hat{\alpha}_{pv} \in [0,1]$ 作为替代。实验证明该自报分数与经验错误继承率呈现单调关系。
- **拓扑无关**：DAG 展开可覆盖序列化、层次化、去中心化等任意 MAS 拓扑。
- **在线计算**：只需一次拓扑排序前向遍历，复杂度为 $O(|V|+|E|)$。
- **理论性质**：证明输出有界（$0 \le r_v \le 1$）、非单调累积（批判可降低下游不确定性）、线性可扩展。

- PropUQ-MAS 在最终输出 UQ 上带来显著提升：平均相对增益 **AUROC +6.10%**、**PRR +47.58%**（具体场景中位数增益为 AUROC +7.32%、PRR +41.36%）。

- 传播规则在更长顺序链和更宽层次结构中均能有效跟踪不确定性，说明其可扩展性。
- 自报的接受权重 $\hat{\alpha}$ 提供了比统一传播更强的边缘信号，消融实验确认其必要性。
- 与采样式基线相比，PropUQ-MAS 不仅 UQ 更强，而且计算开销低两个数量级，适合实时在线监控。

## 7. 优点

- **拓扑无关**：DAG 展开统一了多种 MAS 交互结构，无需为具体拓扑定制。
- **在线可计算**：单次前向遍历即可获得所有节点的不确定性，支持实时干预。
- **训练无关**：可直接叠加于任意现有单智能体 UQ 方法之上，模型无关。
- **理论扎实**：有界性、衰减性、线性复杂度均有证明。
- **可解释性强**：案例展示了如何通过传播感知不确定性识别“局部自信但整体有误”的失败模式。
- **校准灵活性**：边缘权重可由自报分数替换为校准/学习估计，适应不同资源场景。

## 8. 不足与局限

- **代理参数不精确**：在线使用自报 $\hat{\alpha}$ 替代真实错误条件参数 $\alpha$，虽验证了单调性，但并非严格校准的概率。
- **独立性假设较强**：边间污染独立、局部错误与污染独立的前提可能在严重提示注入、上下文过载或联合推理场景下被违反。
- **依赖局部 UQ 质量**：若局部不确定性本身校准差，传播结果也会受影响（论文也承认这一点）。
- **实验范围有限**：数据集集中在数学/科学/代码推理，缺少开放域、长程工具调用等更真实复杂的 MAS 场景；采样基线对比仅一个数据集。
- **基础模型覆盖**：主要基于开源模型（Qwen3、Gemma），未涉及商业 API 模型；且最大规模为 14B，规模上限有限。
