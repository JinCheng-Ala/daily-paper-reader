## 摘要
大型语言模型代理越来越依赖长时程推理来解决涉及规划、工具使用和记忆的复杂任务。在此类场景中，一个关键能力是反思：评估轨迹进展，识别缺失证据和不可靠的中间状态，并决定是继续、修正还是放弃当前分支。然而，学习有效的反思具有挑战性，因为反思是在当前分支内局部执行的，而其效用只能通过其对最终轨迹结果的贡献来确定。这种局部与全局的不匹配使得基于结果的学习只能为反思决策提供局部、稀疏且延迟的监督。为解决这些问题，我们提出了LoongReflect，一个将反思形式化为记忆控制策略的训练框架。代理通过显式的反思和回溯操作在可逆轨迹树上运行。反思将已验证的事实、缺失证据和分支特定风险整合到工作记忆中，而回溯则从活动上下文中移除不可靠的分支并保留简洁的纠正性教训。为学习该策略，LoongReflect通过一种前瞻式的、类似额外梯度的协调机制结合两种互补信号。快速通道从特权教师那里提炼全局信息化的反思行为，监督仅限于反思和回溯标记。慢速通道使用基于结果的GRPO优化完整轨迹，将局部控制决策与最终任务成功对齐。在多跳检索增强生成和数学推理基准上的实验表明，相较于仅基于结果的学习和自蒸馏基线，该方法取得了一致的改进。

## Abstract
Large language model agents increasingly rely on long-horizon reasoning to solve complex tasks involving planning, tool use, and memory. A critical capability in such settings is reflection: assessing trajectory progress, identifying missing evidence and unreliable intermediate states, and deciding whether to continue, revise, or abandon the current branch. Learning effective reflection, however, is challenging because reflection is performed locally within the current branch, whereas its utility can only be determined by its contribution to the final trajectory outcome. This local-global mismatch makes outcome-based reinforcement learning provide only local, sparse and delayed supervision for reflective decisions. To solve these, we propose LoongReflect, a training framework that formulates reflection as a memory-control policy. The agent operates over a reversible trajectory tree using explicit reflect and backtrack actions. Reflection consolidates verified facts, missing evidence, and branch-specific risks into working memory, while backtracking removes an unreliable branch from the active context and preserves a concise corrective lesson. To learn this policy, LoongReflect combines two complementary signals through a look-ahead, extragradient-style coordination mechanism. A fast channel distills globally informed reflective behavior from a privileged teacher, with supervision restricted to reflection and backtracking tokens. A slow channel optimizes complete trajectories using outcome-based GRPO, aligning local control decisions with final task success. Experiments on multi-hop retrieval-augmented generation and mathematical reasoning benchmarks demonstrate consistent improvements over outcome-only reinforcement learning and self-distillation baselines.

## 2. 论文提出的方法论

### 2.1 核心思想

LoongReflect 将反思形式化为一种**记忆控制策略（memory-control policy）**：反思不再是形式上松散的文本反馈，而是对推理记忆的显式结构化决策——决定应保留、修正还是丢弃什么信息。代理在**可逆轨迹树（reversible trajectory tree）**上运行，使用两个显式控制动作：

- **`<reflect>`**：把已验证事实、缺失证据和分支特定风险整合到工作记忆中，输出结构化诊断（证据、风险、返回点、控制意图）。
- **`<backtrack>`**：当当前分支不可靠时，从活动上下文中移除受污染的轨迹后缀，恢复到已验证的状态，并保留一条简洁的纠正性教训（lesson）供后续决策使用。

### 2.2 关键技术细节

**（1）可逆轨迹树状态表示**

在每个时间步 t，代理状态 z_t = (x, T_t, P_t, m_t)，包含轨迹树 T_t、活动路径 P_t 和工作记忆 m_t。回溯时：P_{t+1} = P_j ⊕ u_{j:t}（恢复的激活前缀加纠正性更新），失效后缀存入归档分支。模型上下文仅序列化活动路径与压缩记忆，历史分支内部保留用于诊断与监督。

**（2）双通道优化框架**

- **快速通道（Fast Channel）— 答案掩蔽的局部蒸馏**：EMA 教师基于全局轨迹记录（含归档分支和最终结果）构造结构化提示 h_t，但掩蔽最终答案；学生与教师共享同一 on-policy 前缀和延续，仅在 `<reflect>` 和 `<backtrack>` 的 token 上施加掩蔽反向 KL 目标，提供密集的局部诊断与恢复监督，避免答案模仿。
- **慢速通道（Slow Channel）— 基于结果的全局优化**：在完整轨迹上应用基于组相对优势 bÂᵢ 的 GRPO（含 PPO 式裁剪与 KL 正则），仅对最终活动执行中的策略 token 计算损失，用最终任务成败校准反思的全局效用。
- **前瞻协调（Look-Ahead Coordination）**：先执行 K 次快速通道内部更新得到临时策略 θ̃，再在该策略上评估慢速梯度 g_s，若快速方向 g_f 与 g_s 冲突（内积为负），则去除 g_f 中沿 g_s 的反对分量；随后融合两方向进行外部更新。

### 2.3 伪代码流程（文字说明）

每个外层步骤：采样 8 个提示词、每提示词 4 条轨迹 → 构建可逆树与终端奖励 → 构建答案掩蔽提示与控制 token 掩码 → 快照参数 → 执行 K=3 次快速更新 → 保存临时策略并在其上计算慢速梯度 → 快照慢速更新后参数 → 计算两个参数位移的方向冲突，按需去除冲突分量 → 提交融合更新 → 更新 EMA 教师。

## 6. 论文的主要结论与发现

1. **LoongReflect 在全部 7 个 QA 基准上取得最优成绩**：3B 模型平均 F1 达 46.15，7B 模型达 49.21，分别超过最强基线 AgenticRAG-R1 达 12.60 和 12.61 个百分点；域外任务提升显著，说明反射能力有泛化性而非仅在域内拟合。
2. **反思能力可迁移至数学推理**：3B 模型在 MATH 上达 56.0、GSM8K 上达 82.4，优于 AgenticRAG-R1 和 RLSD，表明与检索解耦的诊断–恢复行为对多步推理同样有益。
3. **SFT 与两通道 RL 各有贡献且后者增益更大**：SFT 相对 RAW 平均提升 3.54~4.43 点，两通道 RL 再提升 7.94~11.39 点。
4. **各组件均不可或缺**：移除 `<reflect>` 使平均 F1 下降 15.31 点；移除 `<backtrack>` 下降 13.06 点；移除慢速优化、快速蒸馏、前瞻协调分别下降 7.04、5.64、4.94 点。
5. **前瞻协调机制有效**：训练中任务奖励上升的同时蒸馏奖励从强负值向零收敛，说明策略在遵循教师局部指导的同时未牺牲最终轨迹结果。

## 8. 不足与局限

论文在附录 K 中明确承认了以下局限，此外补充如下分析：

1. **依赖检索质量与控制器判断**：检索噪声可能影响已验证状态的构建、检查点选择和压缩更新质量；早期诊断错误可能沿后续搜索与答案决策传播。实验未量化对检索噪声的鲁棒性边界。
2. **奖励设计与判断偏差**：归一化精确匹配（EM）奖励可能低估语义合法的别名变体（F1 可部分缓解但 EM 不敏感）；EMA 教师的二元终端结果也可能影响局部诊断的风格与判断倾向。
3. **实验覆盖有限**：训练数据仅来自 HotpotQA 与 2WikiMultiHopQA 两个数据集；未覆盖如代码生成、工具规划等其他长时程任务场景；数学推理仅为迁移验证，训练中未包含任何数学数据。
4. **多次运行与统计检验不足**：主体实验为单一固定种子（seed 1234/42），缺乏多独立种子的方差报告与显著性检验，结论的统计稳健性有待加强。
5. **计算成本较高**：3B 与 7B 均需 100 外层步（每步 32 条轨迹）、3 次快速 + 1 次慢速更新、外加 Qwen3-32B 教师在线推理；回溯机制与三快一慢的前瞻更新增加了推理与优化开销，大规模部署成本需进一步优化。
6. **协调机制仍有手工成分**：K=3 与 w=1 是通过小范围搜索确定的固定超参数，自适应或可学习的协调策略尚未探索。
