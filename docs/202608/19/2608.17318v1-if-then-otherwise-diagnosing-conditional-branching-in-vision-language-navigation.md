## 摘要
视觉语言导航智能体通常通过其遵循路线式指令到达固定目标的能力进行评估。然而，真实的导航指令往往依赖于所观察到的环境状态：如果条件成立，则沿一条路径前进，否则走另一条。这类指令要求智能体评估场景证据，选择正确的逻辑分支，并执行相应的导航行为。现有评估对条件分支执行的控制有限，难以判断智能体失败是由于感知、接地、导航还是逻辑决策。我们提出了CondVLN，一个基于场景图接地基准，用于诊断视觉语言导航中的条件分支。CondVLN以程序化方式生成指令，其分支条件基于可验证的3D场景图谓词接地，并在分支深度、依赖链长度、空间组合、证据可观察性和指令视野方面进行受控变化。CondVLN包含跨AI2-THOR、Matterport3D、Gibson和ReplicaCAD的超过11,500条生成的条件指令，并使用标准VLN指标和分支特定诊断来评估智能体：分支选择准确率和条件成功率。评估四个最先进的VLN智能体（VLN-Zero、NaVid、NaVILA和Open-Nav）表明，条件分支暴露了仅通过标准成功率或路径长度无法捕获的失败：智能体可能以看似合理的方式导航，却提交了与所观察场景条件不一致的分支。我们还提出了一种轻量级神经符号分支选择模型，将条件接地与导航执行分离，将性能提升了2倍。CondVLN提供了一个可复用的测试平台，用于衡量具身智能体是否不仅能遵循指令，还能在正确条件下遵循正确的指令。

## Abstract
Vision-language navigation agents are often evaluated on their ability to follow route-like instructions toward a fixed goal. Yet, real navigation instructions often depend on observed states of the environment: if a condition holds, then follow one path, otherwise take another. Such instructions require an agent to evaluate scene evidence, select the correct logical branch, and execute the corresponding navigation behavior. Existing evaluations provide limited control over conditional branch execution, making it difficult to determine whether agents fail because of perception, grounding, navigation, or logical decision-making. We introduce CondVLN, a scene-graph-grounded benchmark for diagnosing conditional branching in vision-language navigation. CondVLN programmatically generates instructions whose branch conditions are grounded in verifiable 3D scene-graph predicates, with controlled variation in branch depth, dependency chain length, spatial composition, evidence observability, and instruction horizon. CondVLN contains over 11,500 generated conditional instructions across AI2-THOR, Matterport3D, Gibson, and ReplicaCAD, and evaluates agents using standard VLN metrics and branch-specific diagnostics: Branch Selection Accuracy and Conditional Success Rate. Evaluating four state-of-the-art VLN agents (VLN-Zero, NaVid, NaVILA, and Open-Nav) shows that conditional branching exposes failures that are not captured by standard success rate or path length alone: agents can navigate plausibly while committing to a branch inconsistent with the observed scene condition. We also present a lightweight neurosymbolic branch-selection model that separates condition grounding from navigation execution, improving performance by 2x. CondVLN provides a reusable testbed for measuring whether embodied agents can not only follow instructions, but follow the right instruction under the right condition.

## 二、方法论

### 核心思想

CondVLN 以**分层 3D 场景图**为纽带，将环境中的物体—物体、物体—房间的空间语义关系编码为可验证的符号谓词，并在此基础上**程序化生成**条件导航指令。所有条件逻辑均显式接地于场景图的谓词，分支的真值在生成时已知，从而支持自动化的分支级诊断。

### 关键流程（四步）

1. **统一场景层次表示**：将四个异构数据集（AI2-THOR、MP3D、Gibson、ReplicaCAD）的不同格式注释转换为通用层次结构（房间 → 物体语义标签 + 3D 中心坐标 + 几何元数据如 AABB）。
2. **语义与空间关系生成**：构建有向关系图，对每个有序物体对生成：
   - **规范方向谓词**：方位角离散化为 8 个扇区（东、东北、北……），俯仰离散化为上/平/下，组合为如“东部偏上”等谓词；
   - **语义关系谓词**：根据保守度量阈值生成近/远、高于/低于、上方/下方等；
   - **距离指标优先回退**：依次使用 AABB 表面距离 → 球体表面距离 → 中心距离，以适应不同数据集的几何信息差异。
3. **条件指令合成**：
   - 使用结构化模板，核心形式为：`IF condition THEN action ELSE action`；
   - 条件为物体存在性查询，动作对应导航目标；
   - 覆盖六种复杂度类别：简单、嵌套、深度嵌套、链式、长链、嵌套链（沿逻辑深度与链长两个维度变化）；
   - 无效条件引用通过“场景中存在但不在此房间的物体类别”来构造受控的假分支。
4. **VLN-CE 数据集实现**：将生成的指令转换为 Habitat 兼容的 VLN-CE 格式（含场景 ID、起止坐标、旋转、指令文本、参考路径、测地距离），与现有 VLN 生态（VLN-Zero、NaVid 等）无缝对接。

### 评估指标（分支级诊断）

- **分支选择准确率（BSA）**：衡量智能体沿正确分支前进的比例，允许部分分支进度的分数式计分。
- **条件成功率（CSR）**：严格要求智能体完整跟随正确分支**且**最终任务成功，是更严格的指标。
- 这两个指标与标准 SR、SPL 配合，可区分“导航成功但分支错误”与“分支正确但导航失败”两类截然不同的故障。

### 神经符号 Oracle 基线

- 使用构建时记录的场景图符号元数据，将条件指令重写为线性导航指令（如“去 gtrue”），从智能体面对提示中移除分支选择难度，但保持目标、子目标、路径等底层 episode 完全不变。
- 作为诊断探针，它将“分支选择”与“导航执行”解耦，用于估计：若逻辑分支已由符号推理正确解析，下游导航性能能提升多少。

## 三、实验设计

### 数据集与场景

- **AI2-THOR**：合成交互式室内场景
- **ReplicaCAD**：高保真公寓级合成场景
- **Matterport3D（MP3D）**：真实扫描室内环境（90 个属性）
- **Gibson**：扫描真实室内空间（572 个场景，其中 105 个含场景图）

CondVLN 生成的指令总数超过 **11,500 条**，覆盖四种环境，指令复杂度跨越多个层次（深度 d=1~3，链长 ℓ=1~3）。

### 候选方法

| 模型 | 特点 |
|---|---|
| VLN-Zero | 基于场景图结构的零样本推理 |
| NaVid | 视频基 VLM 规划 |
| NaVILA | 腿足机器人视觉-语言-动作模型 |
| Open-Nav | 零样本 LLM 推理 + 时空思维链规划 |
| **Oracle（神经符号基线）** | 使用 oracle 场景图信息重写线性指令 |

### 实验设置

- 所有模型使用统一 VLN-CE 兼容评估接口，不进行重训练以保证可比较性。
- 动作预算与指令长度成比例；成功距离阈值：ReplicaCAD 为 0.5 m，其他多房间数据集为 1.0 m。
- 对条件任务，智能体不获得任何显式分支注释，必须自行推理。

## 六、主要结论与发现

1. **条件分支显著暴露现有模型缺陷**：标准 SR 可能达到非平凡水平，但 BSA/CSR 往往远低于 SR，说明智能体可能以“看似合理”的路径到达终点，却选择了与场景条件不符的分支。仅靠 SR/路径长度无法捕获此类故障。
2. **不同模型的表现差距明显**：
   - NaVid 和 NaVILA 在所有环境和复杂度下表现弱，尤其难以处理组合性条件推理；
   - Open-Nav 和 VLN-Zero 表现较好，前者凭借 LLM 推理与时空思维链，后者依赖显式场景图结构。
3. **复杂度上升导致性能一致下降**：无论是增加嵌套深度还是链式分支长度，BSA 和 CSR 均系统性退化，证实了基准对推理复杂度的有效“压力测试”能力。
4. **神经符号分解在高复杂度下优势显著**：Oracle 模型在 d=3 和 ℓ=2 等困难设置下性能提升约 **2 倍**，表明当推理复杂度增加时，**显式符号结构 + 神经感知**的神经符号范式优于纯端到端学习或纯 LLM 推理。
5. **标准 VLN 评估体系需要补强**：条件分支推理应作为 VLN 评估的一项独立维度，而非辅助增强项。

## 七、优点

### 方法/设计亮点

1. **条件逻辑可验证接地**：所有分支条件均基于场景图谓词（物体存在性 + 空间关系），真值在生成时已知，保证了条件的不模糊性和可验证性，这是现有数据集无法做到的。
2. **可控复杂度框架**：沿“逻辑深度”与“链长”两个正交轴系统地变化推理难度，支持细粒度归因分析，这是 NavSpace、LH-VLN 等基准所缺乏的。
3. **跨环境泛化能力测试**：在合成与真实扫描环境上同时实例化，能检验基准生成框架的通用性及不同建模假设（几何元数据差异）下的适应性。
4. **分支级诊断指标设计巧妙**：BSA 提供分数式部分进度反馈，CSR 提供严格的全成功条件，二者结合可分离“分支错误”和“导航失败”。
5. **神经符号 Oracle 探针简洁有效**：基于数据集构建链路重写指令，不需修改底层 episode 即可将符号分支选择与下游导航执行解耦，是诊断工具的很好范式。
6. **与现有 VLN 生态高度兼容**：采用 VLN-CE 标准 JSON 格式和 Habitat 路径查找，几乎无需修改即可使用现有评估框架。

## 八、不足与局限

### 实验覆盖限制

- 仅覆盖 **VLN-CE 兼容的室内数据集**，未涉及室外、开放世界或动态环境，限制了结论的一般性。
- ReplicaCAD 与其他数据集的成功阈值不同（0.5 m vs 1.0 m），可能对模型的跨环境公平比较带来轻微偏差。
- 场景语义注释存在不完美之处（尤其扫描类数据集 MP3D/Gibson），可能影响感知接地的评估准确性。

### 方法局限

- 空间关系生成使用**固定几何启发式**（固定阈值、离散方位扇区），对场景分布差异、新型环境或更复杂的空间关系（如遮挡、边界情况）可能不够稳健。
- 与障碍物和可通行区域相关的导航可行性约束在指令生成阶段未完全显式建模，可能导致部分生成的指令虽然在场景图层面成立，但实际路径曲折或难以执行，增加了评估噪声。

### 偏差风险

- Oracle 基线使用场景图的 oracle 信息重写指令，**规避了真实智能体面临感知不确定性**，因此其性能提升代表的是“上界估计”而非真实可实现水平，不能直接作为实际系统部署的性能参考。
- 样本量在部分环境（如 Gibson 上所有模型 SR 极低）可能不足以支持强统计结论，导致表 2 中部分数值（如 1.0%）的稳定性存疑。

### 应用限制

- 未在实体机器人上验证，限制了结论向真实世界的迁移性。
- 基准集中在离散的目标驱动导航任务上，未涉及多智能体协作、动态人类参与或语义操作等更高阶的具身推理场景。
