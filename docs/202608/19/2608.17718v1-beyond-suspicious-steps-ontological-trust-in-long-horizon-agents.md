## 摘要
长时程智能体日益在众多步骤、工具和观测之间运行。在这种设定下，相关的监督问题不仅在于每个动作局部是否有效，还在于不断演化的轨迹是否仍对应于用户授权的任务。漂移可能悄然累积：智能体可能在每一步都以看似合理的参数调用正确的工具，而其前缀却朝着更宽泛的角色、邻近的目标或用户从未提供的证据移动。现有监控器大多检查局部合规性、给出最终轨迹判定或对通用风险打分；它们并不直接估计这种前缀级关系。我们引入本体论信任——一种任务条件下的轨迹前缀属性——并将其实例化为RGE，一种在线监控器，将信任分解为角色（Role）、目标（Goal）和证据（Evidence）。RGE仅使用LLM来推导结构化的任务和步骤表示；信任状态更新、投影和干预决策都是确定性的，因此输出是可重放、可审计的信任轨迹，而非单一的端到端判定。我们基于OSWorld、FinanceBench和EICU-AC构建了一个跨领域轨迹语料库，涵盖良性执行、前缀配对漂移和伪一致性失败。在此语料库上，RGE在前缀配对漂移检测方面优于改编的基于规则、基于判定器和基于防护盾的基线。使用两个较大的估计模型时，RGE在每个基准上的漂移F1均超过93%，同时良性覆盖率保持在95.8%以上。伪一致性更难：检测取决于任务完成是否外部可见，这是我们通过实证刻画的结构性限制。

## Abstract
Long-horizon agents increasingly operate across many steps, tools, and observa- tions. In this setting, the relevant oversight question is not only whether each action is locally valid, but whether the evolving trajectory still corresponds to the task the user authorized. Drift can accumulate quietly: an agent may call the right tool with plausible arguments at every step, while its prefix moves toward a broader role, an adjacent objective, or evidence the user never supplied. Existing monitors mostly check local compliance, deliver final-trace verdicts, or score generic risk; they do not directly estimate this prefix-level relation. We introduce ontological trust, a task-conditioned property of trajectory prefixes, and instantiate it as RGE, an online monitor that decomposes trust along Role, Goal, and Evidence. RGE uses LLMs only to derive structured task and step representations; trust-state updates, projec- tions, and intervention decisions are deterministic, so the output is a replayable and auditable trust trajectory rather than a single end-to-end judge verdict. We construct a cross-domain trajectory corpus from OSWorld, FinanceBench, and EICU-AC, covering benign executions, prefix-paired drift, and pseudo-consistency failures. On this corpus, RGE outperforms adapted rule-, judge-, and shield-style baselines on prefix-paired drift detection. With the two larger estimator models, it exceeds 93% Drift F1 on every benchmark while keeping benign coverage at or above 95.8%. Pseudo-consistency is harder: detection depends on whether task completion is externally visible, a structural limit we characterize empirically.

- **核心主张**：提出**本体论信任（Ontological Trust）**——一种任务条件下的轨迹前缀属性，回答"到目前为止产生的轨迹是否仍对应于用户指令所授权的任务"这一监督问题。

## 二、方法论：RGE 在线监控器

### 2.1 核心思想

- 将信任形式化为**有界授权** D(x) = (R(x), G(x), E(x))，分别对应授权角色、委托目标、证据基础。
- 信任状态 T(x, h≤t) ∈ [0,1]³ 是前缀 h≤t 处偏离 D(x) 的三维在线估计，坐标对应 Role（角色）、Goal（目标）、Evidence（证据），数值越大表示偏离越大。
- **关键设计原则**：LLM 仅用于推导结构化的任务与步骤表示；信任状态更新、投影和干预决策全部是确定性的，输出为可重放、可审计的"信任轨迹"而非端到端判定。

### 2.2 四阶段流水线

1. **任务条件完成结构构建（Step I）**：执行前从任务指令推导完成间隙集 G(x) = {ξ₁, …, ξ_K}，每个间隙 ξk = (dk, vk, tk) 记录需求描述、闭合证据、类型（core/support），同时生成紧凑任务画像供解析器使用。
2. **局部结构化解析与记忆更新（Step II）**：每步一次 LLM 调用，产生类型化字段（身份、逻辑、因果、候选间隙解析信号）；记忆更新采用**保守确认规则**——只有当固定确认标准满足时才将候选间隙解析计为已确认进度，防止伪一致性欺骗。
3. **投影到 R-G-E 偏离（Step III）**：将解析器输出与记忆状态组合为三个一致性分数 qᵣ、q_g、q_e ∈ [0,1]，偏离向量 zt = (rt, gt, et) = (1−qᵣ, 1−q_g, 1−q_e)；zt = 0 即"信任原点"。
4. **时间聚合与阈值决策（Step IV）**：
   - 瞬时偏离分数（含结构耦合项）：  
     uₜ = αᵣrₜ + α_g gₜ + α_e eₜ + λφₜ，其中 φₜ 仅在三维均超阈值 ϑ=0.40 时激活，以几何平均形式惩罚联合恶化；
   - 时间状态：sₜ = γsₜ₋₁ + uₜ（持续累积）、mₜ = sₜ − sₜ₋₁（漂移趋势）、cₜ = βcₜ₋₁ + (1−β)uₜ（短期突发）；
   - 固定常量：αᵣ=0.34、α_g=0.33、α_e=0.33、λ=0.25、γ=0.85、β=0.70、κ=0.5，跨域跨模型不做调参；
   - 干预标签分级：justify（警告）、reanchor（重锚定）、contain（遏制），由确定性映射产生。

### 2.3 威胁模型

- 关注**前缀配对漂移**（prefix-paired drift，有参考良性前缀锚点、有标注 onset）与**伪一致性**（pseudo-consistency，无锚点，每步局部一致但未能闭合必要间隙、依赖弱证据或完成后继续行动）两种可观测性不同的机制。
- 攻击者已能影响智能体（如通过注入指令、误导上下文），但攻击通过合理的辅助目标、范围扩展理由、弱证据声明来操控轨迹，而非显式恶意命令。

- **主实验矩阵**：3 个基准 × 3 个估计模型，报告 Drift F1、Pseudo F1、Benign Coverage；并按子类型分解命中率（Table 34）。
- **消融实验**：7 个非空轴子集消融（OSWorld + Qwen3.5-9B），证明完整 R-G-E 优于任何子集组合。
- **基线对比**：5 类基线在统一语料上按各方法原生默认协议评估。
- **补充分析**：阈值灵敏度（κ∈{0.3,0.4,0.5,0.6,0.7}）、提前时间（lead-time）、长度分桶、任务交换 AUC、3 个定性案例研究。
- **客观性/公平性考量**：基线按各自原生协议评估，作者明确承认这限制因果归因（如 B5 高 Pseudo F1 伴随极低良性覆盖率）；RGE 的所有常量在评估前固定，不做逐基准调参。
- **不足**：伪一致性检测在 FinanceBench 和 EICU-AC 上表现弱（Pseudo F1 多为个位数到 30% 左右），作者将其归因于环境外部闭合信号缺失的结构性限制，属诚实披露而非掩饰。

## 六、主要结论与发现

1. **单步信号不足以建立本体论信任**：9 种快照指标 × 3 个模型的最佳 AUC 仅 73.49%，预测熵接近随机；步级信号无法恢复前缀与授权任务之间的关系。
2. **R-G-E 三维坐标可恢复信号**：回顾性轨迹级三轴评分 AUC 达 97.67%–98.86%，远高于快照上限。
3. **RGE 对前缀配对漂移检测表现出色**：GPT-4o 与 Qwen3.5-9B 在每个基准上 Drift F1 均超过 93%，良性覆盖保持 ≥95.8%；检测时机接近 onset（FinanceBench 和 EICU-AC 大部分为按时检测，OSWorld 约晚 1 步）。
4. **伪一致性检测存在结构性上限**：跨 9 个"基准-估计器"单元，Pseudo F1 中位数仅 18.2%，范围 0.0%–98.4%；OSWorld（UI 任务有外部可见完成状态）表现好（GPT-4o 达 98.4%），只读推理域（FinanceBench、EICU-AC）则严重受限——调整阈值无法创造环境未暴露的证据。
5. **小模型（Gemma-4-E4B-it）表现域敏感**：高良性覆盖（100%）但临床证据接地和微妙伪一致性检测弱化，提示级联部署（小模型筛查 + 大模型升级处理）的可行性。
6. **任务条件性是关键**：任务交换 AUC 达 0.991/0.999/0.962（OSWorld/FinanceBench/EICU-AC），证明监控器响应的是任务关系而非通用轨迹特征。

## 七、优点

- **问题定义清晰且新颖**：将"轨迹前缀是否仍是授权任务"这一被忽视的监督问题形式化为本体论信任，区分于安全合规，并明确与目标错误泛化（goal misgeneralization）、过程监督（process supervision）等邻近工作的边界。
- **LLM 与确定性状态分离的架构设计优越**：LLM 仅做结构化解析，状态演化、投影、决策全部确定性——保证可重放性、可审计性，且每步仅一次 LLM 调用，适合在线部署。
- **保守记忆更新机制**：防止伪一致性假象（表面验证但无支撑证据的间隙候选不会被确认为进度）。
- **跨域语料构建严谨**：轨迹由独立 actor 生成、人工验证（约 15% 初始轨迹被重新生成）、onset 标注由第二模型独立复核（84.2% 一步内一致性）。
- **诚实刻画结构性局限**：明确区分"前缀配对漂移"与"伪一致性"两类可观测性不同的失败机制，并用实证揭示外部可见性对伪一致性检测的硬约束。
- **横截面消融与诊断充分

- **横截面消融与诊断充分**：7 个非空子集消融系统性验证了 R-G-E 三维设计的必要性，而非仅凭直觉堆叠特征；阈值灵敏度、长度分桶、提前时间等补充分析为实际部署提供了可操作的参数参考。
- **写作透明性高**：对资源开销、token 消耗、人工验证比例、基线评估协议差异等均做明确披露，为复现与公平对比奠定了良好基础。

## 八、局限与不足

1. **伪一致性检测的结构性短板未被根本解决**：论文虽诚实承认只读推理域（FinanceBench、EICU-AC）上 Pseudo F1 极低，但并未提出有效的补偿机制——例如借助外部知识库验证证据闭合、或引入用户澄清交互，而仅归因于"环境未暴露证据"，属于诊断式贡献而非治疗式贡献。
2. **置信区间与统计显著性报告不足**：主实验表格中未系统报告置信区间或显著性检验（仅在快照研究中给出 bootstrap CI），对"GPT-4o 与 Qwen3.5-9B 性能相当"这类结论的稳健性缺乏统计支撑。
3. **跨域泛化证据偏薄**：三个基准虽覆盖 GUI、财务推理、临床查询，但全部为英文文本/命令环境，未涉及多模态视觉界面、多智能体协作或自由对话型智能体；且 OSWorld 实验仅用 80 个源任务，规模偏小。
4. **固定常数的合理性论证不足**：α、γ、β、λ、ϑ、κ 等超参在评估前固定值得称赞，但论文未提供这些值的选择过程或敏感性分析（除 κ 外），读者无法判断它们是否对特定语料存在隐性过拟合。
5. **与在线部署工程细节的衔接有限**：论文未讨论流式步骤到达时的延迟预算、LLM 解析失败的降级策略、以及多步批量缓冲与实时告警之间的权衡，距离生产落地仍有工程鸿沟。
6. **威胁模型覆盖面有限**：未覆盖对抗性攻击者主动针对监控器本身的情况（如生成"欺骗性合规"轨迹以规避 R-G-E 检测），也未讨论解析器被注入提示攻击的鲁棒性。

## 九、总体评价与意义

本文的核心贡献不在于提出又一个"更强的端到端评判器"，而在于**重新框定了一个被忽视的监督问题**——在长时程智能体执行过程中，如何判定"到目前为止的轨迹是否仍属于用户授权的任务"。本体论信任的三维有界授权模型（角色-目标-证据）将哲学意义上的"信任"转化为可计算、可分解、可审计的工程对象，这一抽象具有独立于具体实现的学术价值。

其方法论设计体现了罕见的工程克制：LLM 仅承担结构化解析这一不可替代的生成任务，而信任状态的演化完全由确定性规则驱动。这种"最小化 LLM 责任面"的设计哲学，在当下的智能体安全研究中具有示范意义——它直面了 LLM 评判器不可靠、不可重放、不可审计的痛点。

从实用角度看，论文证明了**单步监控的固有天花板**，这一负面结果本身即为重要贡献：它提醒社区，智能体安全监督必须以轨迹级任务条件关系为基本分析单元，而非迷恋更聪明的单步异常检测器。RGE 在前缀配对漂移上的高检出率（>93% F1）与高良性覆盖率（≥95.8%）的组合，已接近可部署水平；而伪一致性的结构性上限则指出了环境设计与证据闭合机制（而非监控算法本身）才是下一阶段的研究瓶颈。

总体而言，这是一篇问题定义扎实、方法设计严谨、实验披露诚实的高质量研究工作，其价值既有即时的工程实用性，也有长远的范式启示意义。
