## 摘要
我们提出了一种可扩展的无监督聚类框架，用于对来自太字节级自动识别系统（AIS）档案的海事轨迹进行聚类。可变长度的轨迹通过基于BERT的自定义模型进行编码，该模型通过掩码标记建模进行训练，并使用CURE层次聚类进行聚类，无需预定义簇数量即可生成具有物理可解释性的轨迹组。一种基于重建损失和聚类噪声分配的内在无监督异常检测方法可识别异常航行模式。该框架在一个包含数十亿条消息、跨越一年的国家级AIS数据集上进行了验证，产生了稳定的轨迹簇，并清晰区分了正常与异常的船舶行为。

## Abstract
We present a scalable framework for unsupervised clustering of maritime trajectories derived from terabyte-scale Automatic Identification System (AIS) archives. Variable-length trajectories are encoded with a custom BERT-based model trained via masked token modeling and clustered using CURE hierarchical clustering, producing physically interpretable trajectory groups without requiring a predefined number of clusters. An intrinsic unsupervised anomaly detection method based on reconstruction loss and clustering noise assignment identifies irregular navigation patterns. The framework is demonstrated on a national-scale AIS dataset comprising billions of messages spanning one year, yielding stable trajectory clusters and a clear separation between nominal and anomalous vessel behavior.

## 1. 核心问题与整体含义

- **研究动机**：AIS（自动识别系统）数据规模庞大（国家级档案可达 TB 级、数十亿条消息），且存在采样不规则、噪声多、轨迹长度可变等问题，给海事交通分析与异常检测带来巨大挑战。
- **问题定义**：如何在不需要预设簇数量的前提下，对 TB 级 AIS 轨迹进行高效、可扩展的聚类，并在无监督条件下识别异常航行行为。
- **整体思想**：提出 **STCAD** 框架，结合自定义 BERT 式轨迹编码器（掩码标记建模）与 CURE 层次聚类，将可变长度轨迹映射为固定向量，再通过聚类和“重构损失 + 噪声分配”实现异常检测。
- **核心贡献**：在丹麦海事局 2024 年全年国家级 AIS 数据（约 68.9 亿条消息、1.2 TB）上验证了框架的可扩展性和有效性，获得物理可解释的轨迹簇，并清晰区分正常与异常行为。

## 2. 方法论

- **数据预处理**：
  - 两阶段流程：先进行全局过滤（剔除地理范围外消息、SOG>30 节或 COG 越界的数据），再进行逐船（MMSI）处理。
  - 采用分布式 MapReduce 风格流程：按 MMSI 分桶并序列化为 pickle 文件，在 DTU 计算中心并行处理。
  - 轨迹定义：相邻消息间隔小于 2 小时为一段连续航程；大于 20 小时则拆分；少于 4 小时或少于 20 条消息的轨迹被丢弃。
  - 速度异常过滤：经验速度 >40 节的消息被删除。
  - 线性插值实现 5 分钟规则采样，并对每个特征做 min-max 归一化。
- **序列编码**：
  - 使用轻量 Transformer（BERT 风格）：4 层编码器、4 个注意力头、隐藏维度 256，输入特征为 [lat, lon, SOG, COG]。
  - 每个特征向量通过线性映射投影到 256 维，并加入位置编码。
  - 序列开头添加 [CLS] token，其最终隐藏状态作为整条轨迹的嵌入表征。
  - 训练采用掩码标记建模（masked token modeling），掩码概率 15%，dropout 0.1，优化器 Adam，学习率 5×10⁻⁵。
- **层次聚类（CURE）**：
  - 由于标准凝聚聚类（时间复杂度 O(n³)）无法应对大数据量，采用 CURE 算法。
  - 先对 N=1000 的样本执行凝聚聚类，再将剩余点分配到最近的代表性集合，使拟合时间复杂度降至线性。
  - 嵌入向量先做 L2 归一化，使欧氏距离与余弦相似度一致。
  - 设置“分配阈值”，若点到最近簇代表集的距离超过阈值，则标记为噪声。
  - 为排除孤立噪声点对代表集的影响，丢弃前 N·ρ 次合并后仍孤立的样本（ρ=0.05）。
  - 超参数：压缩因子 0.6，代表点数量 20。
  - 对比了不同链接准则：单链接产生严重的链式效应，平均链接导致树状图碎片化，最终采用 WARD 链接。
- **异常检测**：
  - 基于聚类噪声分配：分配阈值决定哪些轨迹被标记为噪声。
  - 同时利用编码器重构误差（MSE）：异常轨迹往往重构误差更高，因为编码器更多学习了常见模式。
  - 定义重构对比比率 RCR = E[MSE_noise] / E[MSE_cluster]，用于量化正常与异常轨迹的分离程度。

## 6. 主要结论与发现

- **可扩展性**：通过分布式预处理和 CURE 线性复杂度聚类，成功处理 1.2 TB 的 AIS 数据，使国家级全年轨迹分析成为可能。
- **聚类可解释性**：
  - k=3 时，一个簇主要位于日德兰半岛北部；k=5 时进一步细分出更局部的区域。
  - 5 簇结果中：C4 以高纬度、低经度、渔船为主；C1/C2 由高速度、大位移的货船/油轮组成，对应基尔运河及通往丹麦港口的航线；C0/C3 主要包含低速度、低位移的游艇/休闲船，分别集中在日德兰南部和菲英岛附近。
- **异常检测**：
  - 噪声轨迹的重构误差显著高于簇内轨迹（RCR=1.5，表明分离有效）。
  - 在选定参数下，噪声轨迹表现出较高速度、较低经度，且更大概率属于“其他”船舶类型，而休闲船只明显较少出现在噪声中，说明休闲船轨迹聚类纯度较高。
- **整体意义**：验证了“BERT 风格编码 + 层次聚类 + 重构误差”在真实大规模、嘈杂海事数据上的可行性。

## 7. 优点

- **规模化设计**：预处理采用分布式架构，聚类采用 CURE，有效解决了大数据量下的计算瓶颈。
- **无监督且无需预设簇数**：通过树状图选择簇数量，适配探索性海事分析场景。
- **自监督表征**：掩码建模可以在无标注数据上学习轨迹结构，适合 AIS 数据难以人工标注的现实。
- **统一的异常检测机制**：将聚类噪声分配与重构损失结合，提供内在无监督异常评分。
- **可解释性强**：簇描述使用物理特征和船舶类型的 Z-score/PMI，地理轨迹可视化直观，便于海事领域专家解读。
- **真实大规模数据验证**：使用了公开可获取的国家级 AIS 数据，数据规模远超许多已有研究。

## 8. 不足与局限

- **缺少量化对比基准**：未与 HDBSCAN、DBSCAN、TrajBERT 等方法对比，也没有聚类指标（如轮廓系数、ARI）或异常检测指标（AUC、F1），降低了说服力。
- **单数据集、单地区**：只在丹麦水域验证，可能难以泛化到其他地理区域、不同 AIS 覆盖或数据质量差异的场景。
- **启发式参数选择**：簇数量、分配阈值、CURE 超参数（ρ、压缩因子、代表点数）均依赖人工初步实验，缺少自动化或敏感性分析。
- **预处理可能引入偏差**：轨迹定义（2 小时间隔、20 小时拆分、4 小时/20 条阈值、5 分钟线性插值）会过滤掉大量轨迹（从 134 万降到 45 万），可能丢弃短途、低速或数据稀疏但有意义的航行行为。
- **异常检测缺乏验证**：没有已知异常标签或事件库，无法确认“噪声”就是真正的异常，可能包括数据质量问题或正常的边缘航线。
- **模型训练细节不完整**：未报告 GPU 数量、训练 wall-time、能耗、显存等资源信息，影响可复现性评估。
- **特征空间有限**：仅使用经纬度、SOG、COG，未利用 AIS 静态或航次特征（作者提及稀疏而排除），可能遗漏重要信息。
