## 摘要
企业业务场景日益复杂，推动了代理系统中长SKILL文档的广泛采用，这给合规检测带来了新的挑战：大模型推理成本高昂，而小模型可能难以保持检测准确性。为解决这一问题，我们提出了SkillCDG，一种基于图的长SKILL合规检测框架。SkillCDG将复杂业务策略表示为两层约束依赖图，其中上层索引SKILL描述以进行场景路由，下层捕获每个SKILL内原子约束之间的依赖关系。在推理阶段，两级检索后接依赖闭包支持合规判断和来源追溯。我们在三个企业数据集和两个受控公共基准变体上全面评估了该框架。实验结果表明，SkillCDG在检测F1分数上比基线方法最多高出12.8个百分点，同时最大节省64.3%的令牌消耗。此外，我们进一步研究了策略图复杂度、模型规模和检测性能之间的内在关系。在单一模型家族的四个检查点上进行的对比实验验证了一个简洁有效的缩放趋势：端到端检测正确性表现出复杂度差异化的缩放模式，从约束依赖图导出的复杂度度量可以有效量化实例难度和模型的性能提升潜力。利用这一有洞察力的缩放趋势，我们进行自适应训练样本选择，并采用在线策略蒸馏来高效提升小规模模型的合规检测能力。

## Abstract
The increasing complexity of enterprise business scenarios has promoted the widespread adoption of long SKILL documents in agent systems, posing new challenges for compliance detection: large models incur substantial inference costs, while small models may fail to maintain detection accuracy. To address this gap, we propose SkillCDG, a graph-based framework for long SKILL compliance detection. SkillCDG represents complex business policies as a two-layer constraint dependency graph, where the upper layer indexes SKILL descriptions for scenario routing and the lower layer captures dependencies among atomic constraints within each SKILL. During inference, two-level retrieval followed by dependency closure supports compliance judgment and source traceability. We comprehensively evaluate the framework on three enterprise datasets and two controlled public benchmark variants. Experimental results demonstrate that SkillCDG outperforms baseline methods by up to 12.8 percentage points in detection F1 score, while reducing token consumption by a maximum 64.3\%. Moreover, we further investigate the inherent relationships among policy-graph complexity, model scale, and detection performance. Comparative experiments conducted on four checkpoints from a single model family validate a concise and effective scaling trend: end-to-end detection correctness exhibits a complexity-differentiated scaling pattern, and the complexity metric derived from the constraint dependency graph can effectively quantify instance difficulty and the performance improvement potential of models. Leveraging this insightful scaling trend, we conduct adaptive training sample selection and adopt on-policy distillation to efficiently enhance the compliance detection capability of small-scale models.

## 2. 方法论

### 2.1 核心思想

- 将长 SKILL 策略文档离线转化为**双层约束依赖图（Constraint Dependency Graph, CDG）**：
  - **上层**：SKILL 级路由索引，保存 SKILL 名称、描述等元数据，用于场景定位。
  - **下层**：每个 SKILL 内部的原子约束规则图，规则之间用统一的 `require` 有向边表示“审计某条规则必须前置评估另一条规则”的强制逻辑依赖。
- 在线推理时执行**两级检索 + 依赖闭包**，构造一个紧凑且逻辑完备的“闭包上下文”供 LLM 判断合规性。
- 每条原子约束保留原始策略文本跨度，实现合规判断的**来源可追溯性**。

### 2.2 关键技术细节

#### （1）规则形式化

- 每条原子规则定义为三元组 \( r_i = \langle c_i, a_i, S_i \rangle \)：
  - \( c_i \)：适用条件；
  - \( a_i \)：规范性动作（required / prohibited / permitted）；
  - \( S_i \)：原始策略文本片段，用于审计溯源。

#### （2）离线图构建（Algorithm 1）

- 将 SKILL 文档按 Markdown 标题边界切分为语义块。
- 对每个块用 LLM 抽取原子规则、识别块内 `require` 依赖，形成局部子图。
- 跨块图融合：去重语义等价规则、合并来源跨度、补充跨块依赖边、去除自环与重复边。
- 最终形成双层 CDG，统一所有边的语义为 `require`（消除知识图谱中关系类型异构问题）。

#### （3）在线推理（Algorithm 2）

- 从交互上下文 \((H, O, A)\) 中提取审计关键词。
- **SKILL 级检索**：按关键词匹配 SKILL 名称和描述，排除无关场景。
- **约束级检索**：在选中 SKILL 内匹配规则的条件、动作、来源文本，得到种子规则。
- **依赖闭包扩展**：从种子规则沿 `require` 出边进行 BFS/DFS，收集所有可达前置规则，得到实例专属闭包子图；若无种子规则，则回退到全量规则以保证覆盖。
- **合规判断**：将闭包渲染为结构化的条件-动作文本，与交互上下文一起送入 LLM，输出违规与否的二分类标签及理由。

#### （4）复杂度度量公式

- 规则密度：\( I_{d,i} = T(R_i) / T(D_i) \)（策略中可审计原子规则 token 占比）。
- 依赖耦合度：\( I_{c,i} = |E_i| / |R_i| \)（平均每条规则的依赖边数）。
- 策略图复杂度：\( C_i = I_{d,i} \cdot I_{c,i} \)（二者乘积，区分“长而稀疏”与“紧凑而强依赖”的策略）。

#### （5）缩放趋势模型（Eq. 3）

\[
\mathrm{logit}\, P(Z_{i,N}=1) = \gamma_{\text{data}(i)} - \eta e^{C_i} + \beta\left(1 - e^{-\rho \tilde{N}^{\alpha}}\right) e^{-\lambda C_i}
\]

- \(\tilde{N}=N/1B\) 为归一化参数规模，\(\tilde{C_i}=C_i/C_0\) 为归一化复杂度。
- 第一项建模“随规模饱和”，第二项为复杂度与规模增益的交互项；通过比较 λ=0 的嵌套模型和加性逻辑模型进行选择。
- 用于预测样本级正确率、估计教师-学生容量差距、指导蒸馏样本选择。

## 6. 主要结论与发现

- **SkillCDG 有效提升长 SKILL 合规检测**：
  - 相比 RawSkill，SkillCDG 在 Qwen3.5-4B 上 F1 提升最高 12.8 个百分点（Fulfillment），在 Qwen3.5-9B 上提升 5.1~10.8 个百分点，在 27B 上 ACC 提升最多 13.2 个百分点。
  - 在公共基准 CompliBench 与 CompliBench-Long 上均一致优于 RawSkill，且长变体上的提升说明其能抵抗无关策略文本干扰。
- **推理成本显著降低**：平均在线 token 消耗分别降低 64.3%（Fulfillment）、33.9%（AfterSales）、39.1%（MerchantSupport）。
- **依赖闭包比关键词检索更关键**：移除闭包导致 F1 最大下降 7.5 点；移除关键词检索主要增加上下文长度与推理成本，并降低部分精度；两者协同最佳。
- **存在复杂度差异化的缩放规律**：
  - 低复杂度样本随模型规模增大快速收敛；高复杂度样本更难判断，但大模型带来的增益也更大。
  - 27B 的外推表现与拟合曲线一致，验证了缩放模型的可预测性。
  - 复杂度度量 \(C_i\) 可以量化实例难度与模型性能提升潜力。
- **缩放引导的在线蒸馏（Scaling-guided OPD）优于均匀采样**：
  - 在相同 2,000 样本预算下，scaling-guided OPD 在三个企业数据集上 ACC/F1 分别提升 2.0/2.0、3.0/1.0、1.3/1.0 点；
  - F1 教师-学生差距恢复率分别为 127.7%、166.7%、39.2%，而均匀 OPD 为 85.1%、83.3%、19.6%；在前两个数据集上学生 F1 甚至超过教师。

## 7. 优点

- **问题建模新颖**：将长 SKILL 合规审计重新定义为“动作条件下的策略逻辑推理”，而非简单的长文本分类或语义检索，切合审计任务的逆向推理本质。
- **结构化表示兼顾效率与完备性**：双层 CDG 同时实现场景路由、条件原子化、依赖闭包与来源追溯；统一 `require` 边语义简化了图操作，避免了通用知识图谱的关系异构问题。
- **闭环可解释性**：从原始策略跨度 → 原子规则 → 依赖闭包 → LLM 判定，每一步可审计、可追溯，并配有案例展示。
- **缩放规律与蒸馏结合**：用 CDG 复杂度量化实例难度，并转化为教师-学生 headroom，直接指导固定预算下 OPD 的样本选择，实现“从分析到训练优化”的闭环。
- **实验设计严谨**：多个模型家族、多个规模、多个数据集；受控的长策略变体（CompliBench-Long）隔离了干扰文本影响；session 分组交叉验证与 bootstrap 置信区间、留一规模外推增强了结论可靠性。
- **实际部署价值**：在显著压缩 token 消耗的同时提升甚至超过教师模型性能，兼顾成本与效果。

## 8. 不足与局限

- **数据可复现性**：三个企业数据集为匿名内部数据，无法公开获取，外部研究者难以完全复现。
- **缩放分析范围有限**：缩放趋势仅在 Qwen3.5 模型家族上验证，未在 DeepSeek、GPT 等跨家族模型上测试，结论的通用性有待检验。
- **蒸馏实验规模较小**：仅使用 2,000 训练样本、单一 4B→9B 配对、单次 seed（17），缺少多 seed 平均与更多规模的证据。
- **部分结果不一致**：在 27B 及部分 DeepSeek、GPT 结果中，ACC 与 F1 差距较大（如 27B 在 Fulfillment 上 ACC 67.6 但 F1 仅 46.5），说明存在类别不平衡下的偏差或阈值问题，文中未充分解释。
- **依赖抽取可靠性依赖 LLM**：离线图的构建依赖 LLM 抽取原子规则和依赖边，虽然有人工评估（规则级别正确率 >98%），但跨域泛化时抽取错误可能被放大。
- **适用边界**：方法主要面向文本型结构化 SKILL（Markdown 分块），对非结构化文本、多模态策略、动态更新的策略支持不足；论文也将多模态与延迟优化列为未来工作。
- **计算开销未完全透明**：离线 CDG 构建成本（LLM 抽取调用的时间与算力）未在实验部分量化，在线 token 节省可能不足以反映全链路总成本。
