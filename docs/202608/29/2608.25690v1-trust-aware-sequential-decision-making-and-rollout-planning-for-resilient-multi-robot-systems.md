## 摘要
多机器人系统中的序贯决策通常假设规划信息可靠且智能体执行规划器预期的动作。被入侵的智能体可能违反这两个假设，导致规划模型与物理执行之间的不匹配。我们在定位欺骗下的在线多机器人路由中研究这一问题。我们引入一个距离约束的欺骗模型，针对监控者感知的对手，以及一种分层二分匹配策略，在限制欺骗规模的同时最大化分配影响。为了缓解此类攻击，我们开发了一个信任感知监控器，结合使用真实GPS欺骗数据校准的概率定位信任和来自任务执行的行为证据，对智能体进行分类，并在后续规划中移除已检测到的对手。我们进一步证明，未检测到的对手可能通过违反规划器-执行一致性而导致Rollout失去预期的成本改进行为。信任感知移除在检测后恢复这一致性，从而实现稳定路由并恢复Rollout相对于基础策略的经验优势。使用真实GPS欺骗数据集和旧金山出租车需求进行的实验表明，在不同欺骗能力、对抗舰队规模、自适应攻击、监控配置和Rollout视野下，检测和弹性路由是有效的。

## Abstract
Sequential decision-making in multi-robot systems typically assumes that planning information is reliable and that agents execute the actions anticipated by the planner. Compromised agents can violate both assumptions, creating a mismatch between the planning model and physical execution. We study this problem in online multi-robot routing under localization spoofing. We introduce a distance-constrained spoofing model for monitor-aware adversaries, together with a tiered bipartite matching strategy that maximizes assignment influence while limiting spoofing magnitude. To mitigate such attacks, we develop a trust-aware monitor that combines probabilistic localization trust, calibrated using real GPS spoofing data, with behavioral evidence from task execution to classify agents and remove detected adversaries from subsequent planning. We further show that undetected adversaries can cause rollout to lose its expected cost-improvement behavior by violating planner-execution consistency. Trust-aware removal restores this consistency after detection, enabling stable routing and recovery of rollout's empirical advantage over the base policy. Experiments using real GPS spoofing datasets and San Francisco taxicab demand demonstrate effective detection and resilient routing across varying spoofing capabilities, adversarial fleet sizes, adaptive attacks, monitoring configurations, and rollout horizons.

### 1. 论文的核心问题与整体含义

- **研究动机**：多机器人系统中的序贯决策（sequential decision-making）通常隐含两个关键假设：一是规划所依赖的信息（如智能体位置、任务状态）可靠；二是智能体会执行规划器所预期的动作。在实际系统中，定位欺骗（localization spoofing）、通信故障或硬件异常可能同时破坏这两个假设，导致"规划模型"与"物理执行"发生失配（planner-execution mismatch）。
- **典型场景**：在线多机器人路由与任务分配（如自动驾驶出行服务、物流配送）。一个被入侵或故障的智能体可以伪造位置信息以吸引任务分配，但实际上不执行服务，从而引发任务重分配、车队容量浪费、服务延误和请求取消，长期累积甚至会使系统失去稳定性。
- **研究问题**：本文聚焦于**定位欺骗**这一代表性攻击。在监控者感知（monitor-aware）的对手模型下，对手会刻意限制欺骗距离以降低可检测性，同时保持对路由决策的干扰能力。论文要解决三个挑战：
  1. 建立能反映对手"影响-可检测性"权衡的威胁模型；
  2. 单一位置证据难以识别小幅或自适应欺骗，需要结合任务执行的行为证据；
  3. 信任估计必须进入规划环路，使被判定不可靠的智能体不再影响后续路由和前瞻决策。

### 2. 论文提出的方法论

- **核心思想**：构建一个**信任感知的序贯规划框架**，将信任作为构造"可信规划状态"（trusted planning state）的机制，而非仅仅作为检测分数。在每个决策时刻，框架综合信息完整性观测与任务级行为证据，将智能体分为三类：合作（C）、可疑（S）、对抗（A）。被检测为对抗的智能体从后续规划中移除，路由基于"可信活跃车队"（trusted active fleet）执行，执行结果又作为未来信任更新的新证据，形成闭环。
- **威胁模型**：
  - 定义了**监控者感知的距离约束欺骗模型**（Definition 3）：对手只能在以真实位置为中心、最大欺骗距离 \(d_{\max}\) 为半径的图邻域内选择上报位置。
  - 提出**分层目标优先级匹配策略**：对手团队通过带权二分匹配选择目标请求，优先级为：最大化同时干扰的请求数量 → 优先干扰距合作服务更近的请求（更低距离层） → 最小化总欺骗位移（公式19与加权匹配22）。
  - 该模型在限制欺骗幅度的同时保持分配影响力，体现了"影响-可检测性"权衡。
- **信任证据机制**：
  - **定位信任**（localization trust）：基于真实GPS欺骗数据校准。先对信号特征用类条件高斯模型与QDA计算后验置信分数，再对每个类别拟合Beta分布；在线观测时，根据归一化定位偏差在合作分布与最隐蔽攻击分布之间插值，生成连续的定位信任观测（公式28-34），并采用滑动窗口聚合和阈值分类（公式37）。

  - **融合规则**：任一支路判定为对抗则融合结果为对抗；两支路都判定为合作才是合作；其余为可疑（公式50）。
- **信任感知Rollout规划**：
  - 以**IA-RA（即时分配+重分配）** 为基础策略；在监控过滤后的可信规划状态上执行**one-at-a-time rollout**（逐智能体改进动作）。
  - 前瞻模型假定可信车队中所有智能体都会执行所分配的动作；若未检测到的对抗者仍留在规划集中，则前瞻轨迹与物理执行轨迹产生分歧（planner-execution mismatch），导致rollout失去预期的成本改进性质。
  - 信任感知移除检测出的对抗者，使规划集与执行集对齐，从而恢复rollout的一致性基础。
- **算法流程**（Algorithm 3）：
  1. 处理定位与行为证据，更新每个智能体的信任分类；
  2. 移除被分类为对抗的智能体，构造过滤后的车队 \(L_{t^+}\) 与可信规划状态 \(\hat x_{t^+}\)；
  3. 生成M个公共需求场景，初始化当前动作为IA-RA；
  4. 逐个智能体用蒙特卡洛前瞻评估候选动作，更新联合动作；
  5. 输出最终rollout命令与过滤后的车队。

### 6. 论文的主要结论与发现

- **单个对抗者即可破坏名义稳定车队**：在IA-RA策略下，即使仅有一个攻击者，也能在足够宽松的欺骗约束下造成路由不稳定（未完成请求与取消数持续增长）。
- **距离约束欺骗降低可检测性但不消除破坏性**：限制欺骗半径能显著缩小定位信任与正常信任的分布重叠，但仍然可维持足够的分配影响力，说明仅依赖定位证据难以应对监控者感知的对手。
- **定位信任与行为信任互补**：定位证据对较大偏差响应快，行为证据在欺骗偏差较小时仍能积累信息；融合监控器效果最优，且合作者误报率低（行为-only无误报）。
- **信任感知移除恢复rollout有效性**：未检测的对抗者使rollout前瞻模型与执行模型不一致，导致成本高企；一旦检测并移除对抗者，规划-执行一致性恢复，rollout在足够视野下能稳定路由并降低未完成请求。
- **视野与容量决定恢复能力**：短视野（H=10）即使有监控也可能无法消除前期累计代价；长视野（H=20/30）及额外合作容量能更好实现恢复，并在高容量下信任感知rollout优于监控IA-RA。

### 7. 优点

- **问题建模完整**：明确区分"感知状态"与"真实状态"、"命令动作"与"执行动作"，为形式化分析规划-执行失配提供了清晰框架。
- **威胁模型切合实际**：距离约束的欺骗模型刻画了监控者感知的对手行为，比无约束欺骗更贴近实际攻击中的隐蔽性考虑。
- **信任机制设计严谨**：定位信任基于真实GPS欺骗数据校准，行为信任利用完整的请求历史，避免仅依赖最终责任人；分类规则保守（可疑态）减少误操作。
- **将信任引入规划环路**：不是单纯检测后告警，而是用来构造规划状态，直接消除失配来源，体现了决策-监控闭环思想。
- **实验覆盖面广**：考虑了多种攻击参数、监控配置、rollout视野和车队容量，并针对现象进行了机制分析（如成本中累计取消项的影响）。
