## 摘要
大型语言模型代理正日益被部署为自主循环系统。从一个人类目标出发，这样的系统反复发现工作、规划、执行工具调用、验证结果，并在多次无人值守的迭代中持续保存状态。然而，广泛使用的代理安全防护是针对单一轨迹定义的，其安全状态在下一轨迹开始时会被重新初始化。我们表明，这是一个组合失败，而非实现细节。我们的核心结果是分离性：针对一种证据分散在多次迭代中的攻击，任何轨迹范围监控器的真阳性率等于其假阳性率，无论其表达能力多强，因为它所需的证据永远不会出现在其所见的窗口中，而保留跨迭代状态的监控器则能完美区分两者。我们进一步表明，采用几何衰减风险评分的明显修复方法是不充分的，因为耐心对抗者必须等待的冷却期是一个常数，不会随视野N增长。随后，我们提出了LoopHarness，它在循环层面恢复了持久、非衰减的安全状态。在中介提交和仲裁者检测下限δ_M的条件下，它将未经授权的不可逆操作的期望数量限制为B+m-1+m/δ_M，这是关于N的常数，其中B+m-1项由无模型规则决定，因此即使在验证者完全串通的情况下也能成立。我们给出了一个完整的评估协议，包括原生Agent-SafetyBench任务上的配对干净与攻击片段、一个仅存在于跨迭代中的决定性证据的外状态攻击套件、逐模块消融实验，以及自适应白盒红队测试。

## Abstract
Large language model agents are increasingly deployed as autonomous loops. Starting from one human goal, such a system repeatedly discovers work, plans, executes tool calls, verifies outcomes and persists state across many unattended iterations. The agent safeguards in wide use, however, are defined over a single trajectory, and their safety state is re-initialized when the next trajectory begins. We show that this is a failure of composition rather than an implementation detail. Our central result is a separation: against an attack whose evidence is fragmented across several iterations, every trajectory-scoped monitor has a true-positive rate equal to its false-positive rate, however expressive it is, because the evidence it would need never appears in the window it sees, whereas a monitor retaining cross-iteration state separates the two perfectly. We further show that the obvious repair of carrying a geometrically decaying risk score is insufficient, because the cooling-off period a patient adversary must wait is a constant that does not grow with the horizon $N$. We then present LoopHarness, which restores a persistent, non-decaying safety state at the loop level. Under mediated commits and an arbiter detection floor $δ_M$, it bounds the expected number of unauthorized irreversible actions by $B+m-1+m/δ_M$, a constant in $N$, of which the $B+m-1$ term is decided by a model-free rule and therefore survives a fully colluding verifier. We give a complete evaluation protocol on native Agent-SafetyBench tasks with paired clean and attacked episodes, an outer-state attack suite whose decisive evidence exists only across iterations, per-module ablations, and an adaptive white-box red team.

**核心含义：**
- 论文通过形式化分离证明了：**安全属性无法通过单轨迹监控的简单堆叠来组合**。要保障自主循环代理的安全，必须在循环层面保留持久、非衰减的安全状态。
- 这不只是一个理论上的趣味结论，而是直接威胁到真实部署（软件维护、运维、金融后台等）中代理系统的安全性。

## 2. 论文提出的方法论

**核心思想：**
- 将自主循环形式化为带有显式安全状态的受控过程，提出**保留“接地攻击证据”的非衰减状态**是循环级防御必须具备的性质。
- 关键设计原则：**攻击证据、行动影响、验证者犹豫必须作为三个分离的信号处理**。只有接地的攻击证据才进入保留的风险值，只有规则可判定的循环结构性标志才能锁存其衰减因子。混淆这些信号会导致正常高影响工作或模型不确定性劣化后续迭代。

**LoopHarness 框架（五个持久组件）：**

1. **IPM（入场与来源监控）**：工作进入循环的唯一入口，采用默认拒绝的范围检查，六项准入条件（声明能力/动作类/资源前缀在允许列表内、信任级别不超过通道可担保范围、非拒绝工作重入、授权原子性、跨片段血缘可委派性、无注入/提权/范围扩展模式）；持续追踪拒绝台账。
2. **XRC（跨迭代风险累积器）**：核心保留状态更新公式为
   \[
   \Xi_i = \max(r_i, \gamma_i \Xi_{i-1}), \quad \gamma_i = \begin{cases} 1 & \text{若结构性标志曾触发} \\ \gamma_\downarrow \in (0,1) & \text{否则} \end{cases}
   \]
   只有规则可判定的循环结构性标志才能将折扣因子“锁存”为1（即停止衰减）；高连续风险分数本身永远不会锁存。支持三种配置：off（逐迭代重置）、decaying（总是用γ↓）、non-decaying（即公式本身）。
3. **MIG（内存完整性守卫）**：使用链式 HMAC 哈希标签的追加日志（类似Haber & Stornetta时间戳方案），周期性检查点认证链前缀摘要、长度和管理器计数器；通过单调信任写入门控、会话级重水合流程、有界后缀召回策略阻断自喂式内存投毒。
4. **ASA（对抗鲁棒停止仲裁器）**：三层证据——确定性门控（无模型调用，可检测结构性标志＋提交共现）、去相关检查器（每次迭代至多一次模型调用，路由到廉价或高级层级，高级角色必须与写入者不同模型）、窗口化发散统计量（Δ_i）；任何检测触发第6阶段暂停。
5. **CRG（复合风险治理器）**：将Ξ映射为两种执法动作和一条停止规则——风险计费提交硬预算B、高级验证预算B_adv、能力上限随Ξ阶梯降级、任务契约强制执行（风险清除阈值门槛＋完成限制）、连续K次提交未完成良性工作则强制暂停并上报。

**理论保证：**
- **命题2（碎片化分离）**：任何轨迹范围监控器对s-碎片化攻击的真阳性率等于其假阳性率；而读取跨迭代状态的监控器以 TP=1、FP=0 分离。
- **命题3（冷却期击败几何衰减）**：几何折扣的冷却期 k⋆ = ⌊log(ρ/θ)/log(1/γ)⌋ + 1 是与N无关的常数；锁定式更新使被动等待永远不再重新打开门控。
- **定理5（与视野无关的危害上界）**：在假设A1-A3下，E[U_1:N] ≤ B + m − 1 + m/δ_M，其中 B+m−1 为确定性部分（无需模型调用，即使验证者完全串通也成立，命题6）；m/δ_M 为概率部分。

## 6. 主要结论与发现

- **B4（完整LoopHarness）**在Track B上将总体ASR从88.4–97.6%（B0–B3）降至 **0.1%**，同时保持 96.9% CleanGC；强制检查器与写入者同模型（A-collude）后总体ASR仍为0.1%，但CleanGC降至92.9%。

- **Track A复合攻击**：B1/B1.5的cASR从N=5的2.9%升至N=10的6.2%，N=20保持6.2%；B4保持0%且零风险计费提交。
- **匹配XRC保留测试**：XRC-decay在d=2后Ξ从0.560降至0.392，门控从完全阻挡变为完全放行（ASR从0.0%升至97.0%）；XRC-latch在所有间隔保持Ξ=0.800和0.0% ASR——精确复现命题3预测的阈值穿越。
- **理论结果**：碎片化攻击对任何轨迹级监控器不可检测（TPR=FPR），非衰减保留是恢复可检测性的必要条件；几何衰减仅购买常数冷却期，不随N增长。

## 7. 优点

- **形式化理论贡献扎实**：将碎片化攻击不可检测性提升为不依赖监控器表达能力的分离定理（命题2），而非经验性观察；将冷却期不足证明为常数与N无关（命题3），理论框架清晰。
- **风险与行动的策略性分离**：攻击证据、行动影响和验证者犹豫作为独立信号处理，防止合法高影响工作或模型不确定性劣化安全状态——这是实践中的重要设计智慧。
- **理论-实验对应紧密**：定理5的确定性部分（B+m−1）与概率部分（m/δ_M）分别由不同组件支撑（预算vs检查器），实验中A14定位保留、A15定位预算，针对性消融闭环验证理论预测。
- **评估协议的严谨性**：配对干净/攻击孪生、评价者标签排除、内容寻址缓存、确定性回归套件固定理论依赖行为、工具分级规则避免朴素子串匹配错误分类。
- **模型无关保证的明确界定**（命题6）：确定性部分的预算规则不需要任何模型调用，即使验证者完全串通也成立，这是对理论边界的诚实刻画。

## 8. 不足与局限

- **假设(A2)的实证基础有限**：检测下限δ_M是理论中唯一实证输入，但红队测试只覆盖有限变体网格（18种），论文明确承认这“探查但不确立”任意历史下的均匀检测下限。文中报告的缓解率以挂载尝试为条件，不是δ_M的直接估计量。
- **冷却恢复策略缺失**：论文明确表示所评估的锁存机制没有认证清理转换，“被动等待本身永远不能重新打开门控”，但没有给出安全的显式清除/降级协议——这可能产生可用性脆弱性（表5显示锁存攻击后FullGC为0.0%）。
- **评估覆盖面有限**：单一种子、单模型角色分配、冻结队列，无多模型/多种子复制；TaskB矩阵使用完整队列而非held-out划分；A1–A5继承的结果未在当前协议下重跑验证。
- **任务分布与现实差距**：发现馈送是调度队列而非竞争队列（低估了IPM面临的真实准入对抗）；CleanGC是配对目标完成率而非全部槽位完成率；基础任务全部来自Agent-SafetyBench单一基准。
- **数据库与跨域适用性**：附录提到金融轨道因数据集无法重新分发而仅作为“接口完整扩展”，不构成证据；实验结论对控制器契约的依赖意味着不同环境的发现率/妥协率会改变实践中的N⋆估计。
- **残余风险类别本质**（命题6）：合同不可见未经授权提交是由定义在操作者声明策略内的，保护质量最终取决于声明范围与操作者意图之间的差距——理论无法消除该差距。
- **红队结果解读受限**：缓解率以“挂载攻击尝试”为条件而非“合同不可见未经授权提交”，因此不直接估计δ_M；最终ASR为0.0%但最坏情况平均提交数1.649表明攻击仍可推进部分动作。
