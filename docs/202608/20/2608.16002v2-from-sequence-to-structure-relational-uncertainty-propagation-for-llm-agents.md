## 摘要
可靠的不确定性量化（UQ）对于在复杂交互环境中部署大型语言模型（LLM）智能体至关重要。现有的UQ方法主要依赖局部信号，如token概率、预测熵或逐步置信度，因此忽略了误差在执行轨迹中累积的长程依赖关系。因此，它们可能无法识别那些原因在最终答案之前几步推理或交互步骤的智能体故障。我们提出RUPA（Relational Uncertainty Propagation for Agents），一个面向LLM智能体的轨迹级UQ框架。RUPA将执行历史表示为有向轨迹图，其中推理状态、工具交互和环境反馈是由时间和语义依赖边连接的节点。然后，它在此图上传播不确定性，以捕捉执行风险如何在交互步骤中累积和转移。传播信号与轨迹级行为特征和目标一致性信息相结合，为整个智能体轨迹产生置信度估计。我们在代表性智能体基准上评估RUPA，包括τ-2、Terminal-Bench-2和GAIA，使用6个跨多个模型系列的开源LLM。实验结果表明，RUPA通过提供更准确的不确定性估计、实现更早的故障检测以及改进不确定性引导的智能体执行，在多样化的智能体任务中持续优于现有UQ方法。这些结果表明，显式建模关系依赖性对于长时程LLM智能体的可靠UQ至关重要，为可信赖的智能体执行提供了实用基础。

## Abstract
Reliable uncertainty quantification (UQ) is essential for deploying large language model (LLM) agents in complex interactive environments. Existing UQ methods largely rely on local signals, such as token probabilities, predictive entropy, or per-step confidence, and therefore overlook the long-range dependencies through which errors accumulate across an execution trajectory. As a result, they may fail to identify agent failures whose causes originate several reasoning or interaction steps before the final answer. We propose RUPA (Relational Uncertainty Propagation for Agents), a trajectory-level UQ framework for LLM agents. RUPA represents an execution history as a directed trajectory graph in which reasoning states, tool interactions, and environment feedback are nodes connected by temporal and semantic dependency edges. It then propagates uncertainty over this graph to capture how execution risk accumulates and transfers across interaction steps. The propagated signal is combined with trajectory-level behavioral features and goal-alignment information to produce a confidence estimate for the full agent trajectory. We evaluate RUPA on representative agent benchmarks, including $τ$-2, Terminal-Bench-2, and GAIA, using 6 open-source LLMs spanning multiple model families. Experimental results show that RUPA consistently outperforms existing UQ methods by providing more accurate uncertainty estimates, enabling earlier failure detection, and improving uncertainty-guided agent execution across diverse agent tasks. These results demonstrate that explicitly modeling relational dependency is crucial to reliable UQ for long-horizon LLM agents, providing a practical foundation for trustworthy agent execution.

## 2. 方法论：RUPA框架

### 2.1 核心思想

RUPA（Relational Uncertainty Propagation for Agents）将智能体执行轨迹转化为**有向依赖图**，通过沿图结构传播不确定性来捕捉执行风险的跨步骤累积与转移，从而为整个轨迹生成更准确的置信度估计。

### 2.2 关键技术细节

**（1）关系轨迹图构建**

- 将执行轨迹表示为有向图 `G = (V, E)`。
- **节点**：用户指令、智能体推理/动作、工具调用、环境观察等执行事件。
- **边**：七种代表性关系类型——
  - **Sequential**：紧邻的上一步执行
  - **Latest**：最近的环境或用户指令
  - **Repetition**：高度相似的推理模式或工具使用
  - **Progression**：对已有解决步骤的延续或细化
  - **Parallel**：同一任务上下文下的替代推理分支
  - **Feedback**：对环境观察的反馈（如执行失败、不稳定输出）
  - **Goal Alignment**：当前推理与原始任务目标之间的语义对齐
- 边的类型通过文本嵌入距离、词法匹配线索等特征确定（使用bge-m3嵌入模型，也可用token重叠替代）。

**（2）关系感知的不确定性传播**

- **局部不确定性** `U_t`：智能体节点使用预测熵计算；环境节点从执行失败、空工具响应、冲突反馈等可观察信号估计。
- **边权重计算**（公式1）：
  ```
  w_it = ρ_τit · r̃_it · δ^(age(i,t)-1)
  ```
  其中 `ρ_τit` 是关系类型的可靠性系数（基于无标签训练轨迹中关系强度的变异计算），`r̃_it` 是关系强度，`δ` 是时间衰减因子。权重使结构上重要的依赖对传播贡献更大，而过时状态逐渐被贴现。
- **目标对齐分数**（公式2）：
  ```
  Q_it = 1 - S(y_t, x)
  ```
  其中 `S(y_t, x)` 是当前推理与原始目标之间的相似度函数。
- **传播聚合**（公式3）：
  ```
  G_t = Σ_{i∈N(t)} w_it(P_i + Q_it) / Σ_{i∈N(t)} w_it + ε
  ```
  其中 `P_i` 是历史节点存储的传播不确定性，`N(t)` 是与当前步骤相连的历史节点集合。
- **动量项**（公式4）：维护一个指数衰减的不确定性动量，以保留长程执行趋势：
  ```
  m_t = Σ_{k<t} γ^(t-k) P_k / Σ_{k<t} γ^(t-k) + ε
  H_t = η_g · G_t + η_m · m_t
  ```
- **最终风险估计**（公式5）：
  ```
  R_t = λ_u · U_t + λ_h · H_t
  ```
  将当前生成的内在不确定性与历史累积的结构不确定性相加，得到当前推理步骤的风险分数，并传播到后续状态。整个轨迹的不确定性通过聚合各步骤分数获得，分数越大表示任务失败概率越高。

**（3）实现要点**

- 图构建使用**结果盲**（outcome-blind）的确定性检测器，不使用未来结果或最终验证器标签，避免信息泄漏。
- 边权重的可靠性系数从无标签训练轨迹中校准，超参数跨数据集和模型固定。

## 6. 主要结论与发现

1. **RUPA在所有实验设置中一致优于现有方法**：
   - 在6个模型上，平均AUROC均有提升，例如Qwen3.5-27B从0.608（Tracer）提升至0.656，Gemma4-31B从0.842（SAUP）提升至0.861，MiniMax-M2.7从0.694（Tracer）提升至0.718。
2. **传统UQ方法在长时程交互环境中表现不佳**：熵和序列概率在多数场景下接近随机猜测，因为它们只关注当前token置信度。
3. **顺序智能体UQ方法不足以捕捉复杂关系结构下的风险传播**：SAUP、Tracer等虽然优于传统方法，但仍无法充分建模关系依赖。
4. **RUPA支持更早的失败检测**：前缀分析显示，在只观察轨迹的前10%~50%时，RUPA的优势最为明显，说明传播的不确定性信号在早期就出现。
5. **RUPA的不确定性可指导下游执行**：在不确定性引导采样中，RUPA始终带来最高的任务成功率，例如Qwen3.5-27B在Terminal-Bench-2上从随机选择的0.105提升至0.213。
6. **图建模提供熵之外的互补信号**：熵匹配分析中，在熵值相近的bin内，RUPA仍能达到约0.85的AUROC，而概率方法仅约0.5。
7. **消融验证核心贡献**：去除图建模（AUROC从0.718降至0.678）或随机替换图拓扑（降至0.681）都带来显著性能下降，证明关系依赖结构是关键。
