## 摘要
本文研究了基于大语言模型（LLM）的多智能体系统（MAS）如何支持精算风险建模，特别关注不确定性量化。精算工作流程代表了一种高风险决策支持场景，其中不可靠的输出可能导致错误的风险评估、不公平的定价和不合规的监管。为了解决LLM的概率性质以及智能体之间依赖关系所引入的不确定性，提出了一种多智能体框架，在该框架中，专门化的智能体在中央枢纽下执行数据准备、建模、审查和解释任务。主要贡献是一种使用标记级对数概率和贝叶斯网络进行不确定性传播的新方法。重要的是，对数概率并不被视为正确性或任务成功概率的直接概率。相反，长度归一化的对数概率摘要被转换为校准的任务级置信度估计，然后再纳入贝叶斯网络。结果表明，该框架再现了基线精算性能，同时提供了对工作流稳定性和运行时不确定性传播的额外洞察。

## Abstract
This paper investigates how multi-agent systems (MAS)-based on large language models (LLMs) can support actuarial risk modelling, with a particular focus on uncertainty quantification. Actuarial workflows represent a high-stakes decision-support setting where unreliable outputs may lead to incorrect risk assessment, unfair pricing, and regulatory non-compliance. To address uncertainty introduced by the probabilistic nature of LLMs and dependencies between agents, a multi-agent framework is proposed in which specialised agents perform data preparation, modelling, review, and explanation tasks under a central hub. The main contribution is a novel approach to uncertainty propagation using token-level log-probabilities and a Bayesian Network. Importantly, log probabilities are not treated as direct probabilities of correctness or task success. Instead, length-normalised log-probability summaries are transformed into calibrated task-level confidence estimates before incorporation into the Bayesian Network. Results show that the framework reproduces baseline actuarial performance while providing additional insight into workflow stability and runtime uncertainty propagation.

### 二、方法论

- **系统整体架构**：采用中心化的星型拓扑结构。
  - 一个 **Central Hub（中央枢纽）** 负责协调任务路由、消息传递和运行时监控。
  - 四个专门化智能体围绕中央枢纽协作，智能体之间不直接通信：
    - **数据准备智能体**（数据摄取、清洗、编码）
    - **建模智能体**（构建预测模型）
    - **审查智能体**（评估数据准备与建模结果，可触发修订或终止）
    - **解释智能体**（可解释性、概念对齐（TCAV）、公平性检查）
  - 每个智能体记录输出与元数据；共享存储器保留来自先前阶段的信息。

- **不确定性量化的核心思想**：
  - 不将 LLM 的 token 级 log 概率直接视为任务成功概率，而是将其作为**不确定性特征**，经**校准**后转化为任务级置信度，再输入贝叶斯网络。
  - 这一设计避免了 LLM 可能“流畅但错误”的输出被误认为高置信度的问题。

- **关键技术公式**：
  - 序列概率分解（自回归模型）：  
    \[
    p_\theta(y|x) = \prod_{t=1}^{L}p_\theta(z_t|z_{<t}, x)
    \]
  - 对数概率（log-probability）：  
    \[
    \log p_\theta(y|x) = \sum_{t=1}^{L} \log p_\theta(z_t|z_{<t}, x)
    \]
  - 长度归一化对数概率（避免文本长度对概率幅度的干扰）：  
    \[
    \bar{\ell}(y) = \frac{1}{L} \sum_{t=1}^{L} \log p_\theta(z_t|z_{<t}, x)
    \]
  - 置信度特征转换：  
    \[
    q_i = \exp(s_i), \quad s_i \text{ 为智能体 } i \text{ 的长度归一化对数概率摘要}
    \]
  - 任务成功概率估计（经校准函数）：  
    \[
    P(X_i = \text{success} | q_i) = f_{\text{cal}}(q_i)
    \]
    - 其中 \( f_{\text{cal}} \) 通过验证运行（validation runs）估计得到。

- **贝叶斯网络（BN）不确定性传播**：
  - 将工作流中的每个任务步骤建模为 BN 中的一个节点（如：\(X_1\)=数据准备成功，\(X_2\)=数据审查成功，\(X_3\)=建模成功）。
  - BN 的联合概率分布按图结构因式分解：  
    \[
    P(X_1, \dots, X_n) = \prod_{i=1}^{n} P(X_i | \text{Pa}(X_i))
    \]
  - 条件概率表（CPT）用于量化父节点对子节点的依赖强度；例如工作流成功节点 (`WorkflowOK`) 的 CPT 可建模为“AND”门，即所有父节点成功时工作流才成功。
  - 运行时，每个智能体产出被转化为证据（evidence），通过贝叶斯推理更新后验概率，从而得到整个工作流的置信度以及不确定性传播路径的可视化。

- **网络抽象与现实工作流的折衷**：
  - 贝叶斯网络建模的是工作流的**抽象执行轨迹**，而非全部控制逻辑。
  - 暂不建模时间顺序、任务优先级、重复执行、反馈循环等。
  - 当智能体请求修订时，使用该阶段**最终被接受的输出**作为该节点的证据，从而保持图结构的无环性和可解释性。

  - 20 个系统性扰动的数据集（T1–T20），包含：
    - 缺失值（低/高）
    - 缺失行（低/高）

  - 每个扰动数据集计算严重性指标（行变化、列变化、缺失率、目标偏移、稀疏度、总体稳定性指数（PSI）、相关性偏移）。

- **情景测试**（不同 LLM 温度）：
  - 场景 A：所有智能体低温（0.2）→ 工作流成功率 87.1%

### 六、主要结论与发现

- **性能可靠性**：整个 MAS 在不同后端上实现了至少 80% 的任务成功率；预测性能（RMSE）与基线模型相当，说明系统在保持自动化的同时没有显著牺牲精算预测精度。
- **后端差异显著**：
  - Qwen2.5 7B 在错误检测率（90%）上明显优于 Llama 2 7B（45%）和 Llama 3.1 8B（65%）。
  - Llama 2 倾向更容易 “通过” 工作流，而在遇到扰动时检测和应对能力较弱。
  - 后端模型的选择对工作流安全性有明显影响，需根据应用场景谨慎选择。
- **不确定性传播效果**：
  - 即使单个智能体的不确定性分数较高（约 80%–90%），信息在贝叶斯网络中传播后，工作流整体置信度可能大幅下降（示例中降至 55%）。
  - 这解释了多智能体系统中不确定性“累积”效应，也证明了贝叶斯网络在识别系统薄弱点上的价值。
- **温度情景的灵敏度**：更高温度（更多随机性）直接降低了整体工作流成功概率，尤其是单个智能体（解释智能体）的高温即可导致显著下降（从 59.2% 降至 42.8%）。
- **解释智能体的适用性**：该框架显示解释智能体不仅用于可解释性，也是一种安全护栏（safety guardrail），可以检测概念对齐和公平性问题。

### 七、方法的优点

- **核心创新**：
  - 将 token 级 log 概率转换为**经过校准**的任务级置信度后，再输入贝叶斯网络，避免了对 log 概率的直接误读。

- **评估维度的全面性**：覆盖智能体行为、能力、一致性和安全性，并引入 20 种扰动场景，从多角度验证了框架的有效性。

### 八、不足与局限

- **贝叶斯网络的简化抽象**：
  - 未建模执行顺序、优先级、反馈循环和迭代修订等真实工作流逻辑，后续需扩展到动态贝叶斯网络或影响图。
  - 采用最终被接受的输出作为证据，可能在多轮修订时丢失过程性不确定信息。
- **可迁移性和泛化性有限**：仅在精算数据集上进行了验证；对其它领域（如医疗、金融、法律）的工作流是否适用尚不清楚。
- **模型校准与鲁棒性依赖后端选择**：不同 LLM 的不确定性差异较大，某些模型（如 Llama 2）的错误检测能力明显偏低，系统整体效果受限于所选模型的质量。
- **实验细节与统计严谨性**：
  - 缺少完整的提示词（prompt）模板和超参数设置说明；
  - 运行次数较少，缺少置信区间、显著性检验等统计支撑；
  - 扰动数据集的严重性指标虽丰富，但未对这些指标与不确定性之间进行回归/因果分析，只做了初步描述性对比。
- **部署与计算成本量化缺失**：未报告具体推理时间、API 成本或能源消耗，较难评估实际部署的性价比。
- **不确定性 ≠ 正确性**：作者也明确强调，贝叶斯网络只能帮助监控不确定性传播，而非证明输出正确性，因此系统不能完全替代人工审查。
- **公平性测试的深度有限**：仅比较组间预测与观测值差异，缺乏对敏感属性的详细分析或跨组的深层归因。
