## 摘要
智能体自我进化主要集中于学习如何行动，却忽视了同等重要的能力：学习发现智能体自身未知之处。现有方法通常假设失败发现是给定的，而专注于在识别出失败后如何修复。我们提出疑问：盲点诊断本身是否可以被学习？因此，我们将诊断作为一种独立于执行的能力来研究，并排除了两种替代性的进步来源：执行器自适应和人类监督。在这些约束下，性能不能通过执行器更新或标注示例来提升，迫使所有改进均源于习得的诊断能力。我们提出了SkillMentor，它通过强化学习训练一个导师策略，以生成诊断任务、识别反复出现的失败模式，并将其整理为可复用的纠正技能。在AppWorld和BFCLv3上，SkillMentor平均将执行器性能提升了44.2%。这些结果表明，盲点诊断是一种可学习的能力，使得在不更新执行器权重或依赖人工整理数据的情况下实现自我进化成为可能。

## Abstract
Agent self-evolution has primarily focused on learning how to act, while overlooking an equally important capability: learning to discover what an agent does not know. Existing approaches typically assume that failure discovery is given, focusing on how to repair failures once they are identified. We ask whether blind-spot diagnosis itself can be learned. We thus study diagnosis as an agent capability separate from execution, and exclude two alternative sources of progress: executor adaptation and human supervision. Under these constraints, performance cannot improve through executor updates or annotated examples, forcing all improvements to originate from the learned diagnostic capability. We propose SkillMentor, which trains a Mentor policy via reinforcement learning to generate diagnostic tasks, identify recurrent failure modes, and curate them into reusable corrective skills. Across AppWorld and BFCLv3, SkillMentor improves executor performance by an average of 44.2%. These results suggest that blind-spot diagnosis is a learnable capability, enabling self-evolution without updating executor weights or relying on human-curated data.

## 2. 论文提出的方法论

### 核心思想
- 训练一个独立的 **Mentor 策略 πθ**，其职责不是执行任务，而是诊断另一个智能体（冻结的 Executor πE）的能力缺陷，并将诊断结果转化为可复用的技能，存入外部技能库。
- 诊断问题被形式化为**顺序决策问题**：在每个训练步骤，Mentor 决定生成何种诊断任务以及如何整理纠正技能，目标函数为最大化发现奖励和整理奖励的累积和。
- 通过 **GRPO 强化学习**对发现与整理两个过程进行**联合优化**，形成自我进化的正反馈闭环。

### 三个关键阶段
1. **盲点发现（Blind-Spot Discovery）**
   - Mentor 在无预定义目标的环境中自由探索（multi-step 交互），并通过**多样性缓冲区**防止探索行为坍缩到狭窄模式；
   - 从探索轨迹中批量合成 G=8 个候选诊断任务（要求自然、具体、可验证，且符合硬性风格规则）。
2. **差距评估（Gap Evaluation）**
   - 每个候选任务由强参考模型 M 和冻结执行器 πE 分别完成并打分；
   - 定义**诊断差距** δ = max(0, s_M − s_E)，即强模型与执行器在该任务上的得分差，用作发现奖励；
   - 选择差距最大的任务进入技能整理环节；
   - 使用**线性衰减的差距阈值**（0.5 → 0.2，每步衰减 0.002）以适应盲点差距随技能积累逐步缩小的动态分布。
3. **技能整理（Skill Curation）**
   - Mentor 基于诊断出的失败任务和失败轨迹，通过 **ADD / UPDATE / MERGE** 三种操作生成 G=8 个候选技能；
   - 双重验证：**语法有效性**（符合预定义 Markdown 格式+合法操作类型）和**执行器接地效用**（执行器重新尝试任务，要求改进幅度 Δ > 0.5）；
   - 整理奖励 r_curate = 0.3·f(c) + 0.7·Δ，其中 f(c) 为格式合规二值分数；
   - 另有轻量 **DELETE 机制**：技能检索后成功率低于 0.05 即被淘汰。

### 联合优化目标
- 使用 GRPO 联合优化发现目标 J_disc 与整理目标 J_curate，目标函数为 J_GRPO(θ) = J_disc + J_curate − β·D_KL(πθ∥πref)，裁剪范围 ε=0.2；
- 当诊断差距信号不足时禁用整理项；
- 推理时，执行器按任务描述从外部技能库检索相关技能并前置到提示中，实现**能力边界迁移**。

## 6. 论文的主要结论与发现

1. **诊断是可学习的能力**：RL 训练的 Mentor 在所有执行器和基准上一致击败所有提示式导师，证明诊断受益于优化而非固定提示流程。
2. **学习胜过规模**：仅 4B 参数的 RL 训练 Mentor 稳定优于 DeepSeek-V4-Flash 等大幅更大的提示式模型，说明诊断能力不是模型规模的副产物。
3. **弱执行器受益更大**：相对提升最大的是弱执行器（DeepSeek-R1-Distill-Qwen-7B +46.6%），最弱的是强执行器（Qwen3.5-9B +36.7%），与盲点定义（程序性缺陷）一致。
4. **发现与整理必须联合优化**：去除任一奖励都会导致显著性能下降，分离参数训练也不及共享参数，验证了发现-整理的正反馈闭环假设。
5. **技能是可迁移的**：弱执行器训练的技能可高效迁移到强执行器（often approaching self-trained），而强到弱迁移有限——弱执行器需要更广的程序性知识覆盖。
6. **盲点是动态非平稳的**：随着技能积累，诊断差距从 0.48 降至 0.17 并趋于稳定，需用衰减阈值跟踪不断收缩的差距分布。
7. **强模型依赖是轻量且稳健的**：SkillMentor 仅需强模型充当训练时的单一 LLM judge，部署时完全移除；即使使用便宜一个数量级的 Flash 级 judge，性能损失也不到 1 个百分点。
8. **技能库可解释、可检查**：以 Markdown 文件存储的技能构成了一幅执行器缺陷的直观地图，不同模型家族展现出不同类别的盲点分布。

## 7. 优点（亮点）

- **问题定位独特且有价值**：将“诊断”从执行中分离出来，作为一个独立的学习目标进行显式优化，这是此前被系统性忽略的维度。研究设定极为干净——冻结执行器、零标注数据、外部技能库承载适应性，使得诊断能力可以被隔离研究，因果归因清晰。
- **反馈闭环设计精巧**：发现与整理共享参数、联合训练，形成自我强化的进化循环。差距阈值采用线性衰减策略来适应盲点分布的非平稳性，设计体现了对动态性的自觉把握。
- **严格受控对比**：通过共享架构/技能格式/检索机制的提示导师基线，干净地隔离出 RL 训练的贡献；在零标注约束下排除了需要监督的强基线，实验选择有原则。
- **强模型依赖性最小化**：将强模型角色限制为训练时单一的 LLM judge，部署零依赖；成本敏感性分析（表 5）很有说服力，展示了低价 Flash 级 judge 的可用性。
- **外部技能库的可解释性与可迁移性**：技能存储为人类可读的 Markdown，可直接检查、编辑和跨模型复用；8×8 迁移矩阵提供了丰富的视角来观察盲点的模型特异性与共性。
- **全面的实验覆盖**：从主效果到内部机制（消融）、动态过程（演化曲线）、泛化能力（迁移矩阵）、成本（judge 选择）、稳定性（超参数）均有数据支撑。

## 8. 不足与局限

- **合成任务的生态效度存疑**：Mentor 生成的诊断任务是模型合成的（在真实 API 环境中但与真实用户需求可能有差距），任务奖励依赖于 LLM judge 的自动评分，评判标准与人类判断之间的偏差未被充分探讨。
- **验证基准范围有限**：仅评估了 AppWorld 和 BFCLv3 两个基准（均为工具调用/API 操作类场景），未覆盖多模态、具身决策、开放域对话等广泛领域，方法的普适性仍待验证。
- **强模型参考的残余依赖**：尽管部署时移除强模型，但训练时仍需参考模型来产生差距信号。若环境中没有可用的强模型，整个训练循环就无法启动——论文未讨论参考模型缺失时的降级路径。
- **技能验证阈值是启发式的**：Δ > 0.5 的进入门控、淘汰阈值 0.05、差距阈值衰减调度（0.5→0.2）均需要人工设定，论文虽提供了敏感性分析，但这些超参数的合理性主要靠实验支撑而非理论依据。
- **实验重复次数与显著性**：所有表都附带标准误差，但未报告统计显著性检验（如 t 检验或置信区间重叠分析），跨迁移矩阵中部分数值差异较小，是否具有统计意义不明确。
- **200 步的训练规模可能不足**：从演化曲线看，差距在约 100 步后趋于稳定，但这是否代表达到最优解决性能，还是受限于训练预算，论文未做更长训练的拓展验证。
- **安全性与滥用风险**：论文未讨论诊断能力可能带来的风险——例如，如果 Mentor 策略被用来刻意暴露弱执行器的缺陷，是否可能被用于生成对抗性攻击或利用性诊断；技能库的可编辑性也可能被人为注入有害技能。
- **删除机制的设定较简单**：以成功率单一指标淘汰技能，未考虑技能对特定任务类别的重要性权重或替换技能的过渡策略，可能造成有用但低使用频率的技能被过早删除。
