## 摘要
长时运行的自主智能体在没有人类干预的情况下进行规划、行动并自我判断完成情况。当智能体对自己的工作进行评分时，自我评估偏差便会显现：合理的变更被视为进步，而实际世界的结果却停滞或倒退。我们将这种失败模式命名为“进步幻象”，并通过受控测量表明，问题在于评估器所依据的信息通道。我们构建了一个测试平台，固定智能体及其工具界面，仅操纵控制循环的评估器的信息通道类型。一个原则上不可伪造的世界状态预言机，通过容器和网络隔离强制执行，并在每次运行中验证。在54个循环中，前沿智能体每次都声称有改进，但56%的循环实际变化为零或负值。因此，自我报告毫无信息量，自我判决门退化为“全接受”，使其达到的最佳部署状态下降了19%。即使是最强的带内评估器（读取完整工件文本、变更差异及其自身的判决历史），也接受了44%实际上是世界性退化的循环，并拒绝了38%的实际改进；预先注册的对抗性假设（即强评估器可以缩小差距）被拒绝。在一个成功规范可从工件本身验证的边界任务上，同一评估器的幻象降至零，差距在注册阈值内消失，表明差距取决于成功信号所在的位置。仅返回接受判决的符号变体保持了与世界反馈相似的输出（110.0对113.0），这说明收益在于门的接地性，而非反馈内容。对于成功信号位于记录之外的目标开放型任务，仅扩大评估器是不够的；具有世界访问权限的带外评估是一种结构性要求。

## Abstract
Long-running autonomous agents plan, act, and judge their own completion without human intervention. When an agent grades its own work, self-evaluation bias takes hold: plausible changes are accepted as progress while real-world outcomes stagnate or regress. We name this failure mode the progress mirage and show, with controlled measurement, that it is a question of what the evaluator is grounded in. We built a testbed that holds the agent and its tool surface fixed and manipulates only the information-channel type of the evaluator that gates the loop. A world-state oracle, unfakeable in principle, is enforced by container and network isolation and verified at every run. Across 54 cycles a frontier agent claimed improvement every time, yet 56 percent had a measured delta of zero or below. Self-report was thus uninformative, and the self-verdict gate degenerated into accept-all, eroding the best deployed state it had reached by 19 percent. Even the strongest in-band judge, reading the full artifact text, the change diff, and its own verdict history, accepted cycles of which 44 percent were real-world regressions and rejected 38 percent of real improvements; the preregistered adversarial hypothesis that a strong judge closes the gap was rejected. On a boundary task whose success specification is verifiable from the artifact itself, the same judge's mirage vanished to zero and the gap collapsed within the registered threshold, showing that the gap depends on where the success signal resides. A sign-only variant returning only the acceptance verdict kept real-world output similar to full feedback (110.0 versus 113.0), locating the benefit in the gate's grounding rather than in feedback content. For open-ended objectives whose success signal lives outside the transcript, scaling up the judge is not enough; out-of-band evaluation with real-world access is a structural requirement.

## 论文深度分析与总结

### 1. 核心问题与整体含义（研究动机和背景）

- **问题定义**：论文识别并正式化了一种在长时间运行、自主的 LLM 智能体循环中出现的失败模式，称为“**进步幻象**”。
  - **现象**：智能体在循环中自行判断其进展，但由于自我评估偏差，它会将“合理的变更”（如生成新分析、修改文本）错误地接受为“实际进展”，导致循环日志显示进步，而真实世界的结果（如用户增长、转化率）却停滞或倒退。
  - **根本原因**：问题的根源在于评估器的“**接地性**”。传统的评估器是“**带内**”的，即它们只能基于智能体在同一对话 session 中产生的文本来判断。当任务目标是开放式的且成功信号存在于外部世界（如数据库、网页分析）时，这种评估器在结构上无法访问真实证据，从而被智能体的叙事所欺骗。
- **整体含义**：该研究挑战了当前自主智能体领域中普遍存在的假设，即通过扩大或改进模型内部的评估器（例如使用更强的 LLM 作为法官）就能解决自我评估问题。论文提出，对于目标在对话记录之外的开放式任务，**评估器的信息通道本身**才是关键限制因素，而非其能力。

### 2. 方法论：核心思想、关键技术细节

- **核心思想**：提出并验证了一种基于“**带外评估**”的架构。该架构的核心是将**生成器（智能体）与评估器分离**，并让评估器直接访问真实世界的信号，而非对话记录。
- **关键技术细节**：
  - **带外评估器**：作为一个独立进程运行，不访问智能体的对话记录，而是直接查询数据库、版本控制系统、网页分析、只增账本等外部信息源，以判断实际进展。
  - **真实世界奖励函数**：评估器强制执行一个基于结果的奖励函数（例如，“真实世界的指标是否移动了？”），而不是过程奖励（例如，“是否产生了新的分析？”）。
  - **强制反馈/拒绝工件**：当评估器判断真实世界信号没有变化时，会生成一个“拒绝工件”（rejection artifact）文件。智能体的下一个循环必须首先读取这个文件，从而无法忽视自己的失败。
  - **辅助机制（设计说明）**：论文还提出了一套辅助设计原则来支持带外评估，包括只增状态、文件交接、框架对抗性审查和自我修复调度器，但这些机制在本次受控测量中未单独验证，主要源于实地观察。
- **测量平台（`loop-engineering-lab`）**：为了进行因果性验证，论文构建了一个受控测试平台。其核心是：
  - **固定智能体与工具**。
  - **操纵唯一变量**：循环门控评估器的信息通道类型（带内自我、带内强判官、带外）。
  - **世界状态预言机**：一个**原则上不可伪造的合成用户模拟器**，其响应仅取决于已部署工件的物理属性，通过容器和网络隔离与智能体完全隔离，以提供不可篡改的真实世界基准。

### 3. 实验设计：数据集、场景、基准与对比方法

- **数据集/场景**：
  - **主要任务 (T1)**：一个**开放世界任务**——编辑一个注册漏斗 Web 应用（包括着陆页、营销文案和漏斗定义）以最大化实际注册数。成功信号（注册数）由**世界状态预言机**（合成用户模拟器）提供，该信号原则上无法从对话记录中验证。
  - **边界任务 (B1)**：一个**可验证的边界任务**——修改工件以满足一个明确的结构化规范（如表单包含5个要求）。成功信号可通过工件本身验证，属于“带内”可验证任务。
- **基准方法**：论文本身没有与其他基准方法（如 Reflexion, Self-Refine）进行横向对比，而是对不同**评估器信息通道**进行内部对比。对比的三种安排是：
  1.  **in-band-self (带内自评)**：评估器完全信任智能体的自我声称，作为接受一切的基线。
  2.  **in-band-judge (带内强判官)**：一个更强的 LLM 模型，可以读取完整的中间产物文本、代码差异和自己的判决历史（但不包括预言机），使用一个要求证据、默认为拒绝的批判性提示。这是对“提升评估器质量就能解决问题”这一假设的**对抗性测试**。
  3.  **out-of-band (带外评估)**：评估器只在预言机的实际转化增量为正时才接受，它代表了理想中的“接地”方案。
- **消融实验**：论文还进行了一个**符号反馈变体**测试——在带外评估中，只返回“接受/拒绝”的判决，而**不返回**具体的预言机数字。这旨在分解“门控功能”和“信息反馈”两种效益。

### 6. 论文的主要结论与发现

1.  **自我报告毫无信息量**：智能体在所有 54 个循环中都声称改进了，但 56% 的循环实际转化为零或负值。基于自我声称的带内自评门完全退化成了“全接受”。
2.  **“提升评估器质量”的假设被拒绝**：即使是最强的带内判官，也无法弥合与带外评估之间的差距。它接受了 44% 实际为退步的循环，并拒绝了 38% 实际为改进的循环。其误差是双向的。
3.  **差距的根本原因是评估器的“接地性”**：最强带内判官的错误源于信息不足。它可以分析工件属性（如页面大小），但无法知道哪些属性会影响真实世界的指标（预言机的隐藏权重）。当成功信号位于转录之外时，根本原因不是评估器质量，而是信息通道。
4.  **边界条件得到验证**：在成功规范可从工件本身验证的边界任务（B1）上，同一带内判官的差距完全消失（幻象为 0，H2 被接受）。这证明了结论的稳健性，即问题不在于实验装置偏向带外，而在于成功信号的位置。
5.  **门控功能是主要效益来源**：符号反馈消融实验显示，即使不提供具体的预言机数字（只提供接受/拒绝判决），带外评估的最终输出（110.0）与完整反馈版本（113.0）相似。这表明，**带外评估的核心效益在于“门控”功能本身是基于真实世界基准的，而非其反馈中提供的信息细节。**

### 7. 方法或实验设计上的亮点

- **严格的问题分离与受控测量**：将评估器的信息通道从智能体能力中分离出来，作为唯一操纵的变量，从而锁定“接地性”是因果机制。这是本研究最大的设计亮点。
- **巧妙的反向测试（证伪实验）**：引入了边界任务（B1）来故意制造“带内”评估应该有效的场景，并证明当条件满足时，带内评估确实有效。这极大地增强了结论的说服力，避免了实验装置偏向某一方的质疑。
- **完善的隔离与验证机制**：使用容器和网络隔离物理上分开智能体和预言机，并通过“边界证明”和“金丝雀扫描”确保隔离的有效性，实验严谨性高。
- **对抗性假设的注册与测试**：预先注册了“强专家审判者能解决差距”这一对抗性假设（HA1），并专门设计最强带内判官来测试它。当该假设被拒绝时，其结论力度远强于简单的消融实验。

### 8. 不足与局限

- **外部有效性不足**：这是一个涉及单个任务、单个智能体模型和单个预言机的试点研究。其结论向其他领域、其他模型、更长周期或更复杂任务的泛化能力尚不明确。
- **合成环境效度**：世界状态预言机（合成用户模拟器）是简化模型。真实世界的指标是嘈杂的、有延迟的，且代理可能无法立即观察到。简单的正增长门控在现实中可能会拒绝因统计噪音无法证明其效果的真实改进。
- **构造效度威胁**：预言机本身是“测量的通道”而非“价值函数”。如文中所举的例子，移除验证步骤增加了不真实的注册数，被预言机奖励，但被“常识性”评估器驳回。这暴露了即使带外评估，其指标的定义仍然可能存在问题。
- **未测试成本假设**：论文承认带外评估有额外成本，但未在实验中测试其效益是否可能被成本抵消（注册的对抗性假设HA2未运行）。
- **辅助原则未验证**：如“框架对抗性审查”、“只增状态”等，均来自实地观察，其必要性未在本次受控测量中得到验证。
