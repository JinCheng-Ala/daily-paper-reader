## 摘要
随着金融机构从传统预测模型向自主智能体系统过渡，传统模型风险管理（MRM）的静态模型清单要求面临结构性的过时。本文提出一种动态的“清单即代码”（IaC）治理循环，将模型清单视为一个活着的架构组件，而非周期性的文档产物。我们做出四项主要贡献。第一，我们引入了一种校准的自主程度（DoA）实质性评分，具有明确的、分类化的工具复杂度加权方案，以解决朴素加性风险公式中的主导性问题。第二，我们将智能体清单构建为有向无环图（DAG），并定义了一个正式的复合风险传播算法，在该算法下，上游验证失败会对所有可达后代施加风险惩罚。第三，我们开发了一种基于集成思维链（CoT）嵌入的分布余弦漂移的轨迹监控协议，包括构建和认证黄金路径基线的明确程序，一种匹配的bootstrap校准（我们表明这对于避免朴素替代方案中严重的假阳性伪像是必要的），以及一种两阶段响应，将合法的推理变异与有害漂移区分开来，而不要求单一超限事件触发不可逆行动。第四，我们解决了先前文献中基本缺失的实际复杂问题：LLM基础模型版本变更、名义上无环智能体图中的潜在反馈循环，以及一种在风险传播之前进行验证的两阶段执行结构。

## Abstract
As financial institutions transition from traditional predictive models to autonomous agentic systems, the static model inventory requirements of traditional model risk management (MRM) face structural obsolescence. This paper proposes a dynamic Inventory-as-Code (IaC) governance loop that treats the model inventory as a living architectural component rather than a periodic documentation artifact. We make four principal contributions. First, we introduce a calibrated Degree of Autonomy (DoA) materiality score with an explicit, taxonomized tool-complexity weighting scheme that addresses the dominance problem of naive additive risk formulations. Second, we construct the agent inventory as a Directed Acyclic Graph (DAG) and define a formal Composite Risk Propagation algorithm under which upstream validation failures induce risk penalties on all reachable descendants. Third, we develop a Trajectory Monitoring protocol based on distributional cosine drift across ensembled Chain-of-Thought (CoT) embeddings, with an explicit procedure for constructing and certifying the Golden Path baseline, a matched-bootstrap calibration that we show is necessary to avoid a severe false-positive artifact in the naive alternative, and a two-stage response that separates legitimate reasoning variation from detrimental drift without demanding that a single exceedance event trigger an irreversible action. Fourth, we address practical complications largely absent from the prior literature: LLM base-model version changes, latent feedback loops in nominally acyclic agent graphs, and a two-pass execution structure that stages validation ahead of risk propagation.

### 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：传统模型风险管理（MRM）框架基于“静态模型清单”这一假设，适用于输入、输出和参数固定的传统预测模型。然而，以大语言模型（LLM）为基础的自主智能体（Agentic AI）系统因其**非确定性推理路径**、**动态工具调用**、**智能体间按需委托**和**暴露于不受控的上游变更（如LLM版本更新）** 等特性，从根本上违背了静态注册的假设，导致传统MRM框架在结构上过时，无法有效量化和管理由此产生的“**智能体风险（Agency Risk）**”。

- **整体含义**：论文主张，治理智能体AI系统不能是对现有MRM实践的简单修补，而需要进行根本性的架构转变。其核心是将模型清单从一个被动的、周期性的文档记录（Ledger）转变为一个主动的、实时的反馈控制系统（Feedback Control System），即“**清单即代码（IaC）**”。这项工作旨在为智能体风险提供一个统一、结构化的治理闭环，而非一系列孤立的点状解决方案。

### 2. 论文提出的方法论

论文提出了一套名为“**递归治理（Recursive Governance）**”的综合框架，包含以下四大核心组件：

- **2.1 清单即代码（Inventory-as-Code, IaC）架构**
    - **核心思想**：将模型清单视为一个活着的架构组件，而非周期性的文档产物。它像一个“控制回路”，持续发现、注册、验证和监控智能体，且其状态变化会自动触发下游后果（如传播失败）。
    - **四阶段循环**：**发现**（自动扫描智能体配置）→ **注册**（分配ID、计算风险等级、在DAG图中创建节点）→ **验证门**（执行特定等级的行为基准测试）→ **持续监控**（通过遥测数据更新状态）。

- **2.2 校准的自主度（DoA）实质性评分**
    - **核心公式**：`R = α · (I × A) + (1 − α) · T`
        - **`I` (影响分数)**：潜在的财务或运营损害程度 (1-10)。
        - **`A` (自主度)**：人类监督的程度 (1-5)。
        - **`T` (加权工具复杂度)**：按工具类型（如只读、不可逆写入）加权求和，但通过一个上限 `T_max` 来**解决“主导性问题（Dominance Problem）”**，即防止拥有大量低风险工具（如多个只读API）的智能体因工具数量多而被错误评为高风险。
    - **关键特性**：由公式可证明，工具广度本身无法将智能体提升至高等级，从而关闭了一个潜在的作弊（Gaming）向量。同时，高风险等级不自动等同于运行时隔离（Quarantine，见下文）。

- **2.3 基于DAG的复合风险传播**
    - **核心模型**：将智能体清单建模为一个**有向无环图（DAG）**，其中节点是智能体，边表示调用依赖关系。
    - **复合风险传播算法**：当上游智能体的验证失败时，其风险会沿着DAG传播，影响所有可达的后代节点。
    - **阻断规则**：一个智能体（本身未失败）被阻断，当且仅当其祖先集合中存在“失败（Failed）”或“已阻断（Blocked）”的智能体。这一规则**解耦了固有风险等级与运行时状态**，使得高风险智能体不会因自身等级而被自动隔离。论文证明了故障的“爆炸半径”恰好等于其传递后代集合。
    - **两阶段执行**：首先对所有节点进行验证（Pass 1），然后再根据验证结果计算复合风险并确定最终状态（Pass 2）。

- **2.4 轨迹监控：黄金路径与漂移检测**
    - **核心思想**：输出分布稳定不等于推理轨迹安全。论文将智能体的思维链（CoT）作为首个MRM工件进行监控，以检测推理层面的漂移。
    - **黄金路径 (Golden Path)**：通过认证的验证语料库计算出的CoT嵌入向量的中心点，是人类认可的正确推理模式。
    - **漂移指标**：`D_t`，为当前生产环境CoT嵌入中心点与“黄金路径”之间的余弦距离。
    - **匹配自举校准**：论文指出，传统将验证集分成两半来校准阈值的方法，会因样本量不匹配（验证集远大于监控窗口）而产生严重的**假阳性伪像**。因此，提出使用“**匹配自举（Matched Bootstrap）**”校准，即从同一验证集中**独立、不放回地**抽取与生产窗口相同大小的样本来构建零分布，从而精确控制假阳性率。
    - **两阶段响应**：将“值得人工查看”与“值得下线”两个决策分离。**软标记（Soft Flag）** （触发人工审查）和**硬标记（Hard Flag）**（立即隔离并触发传播算法）。

### 6. 论文的主要结论与发现

- **DAG风险传播有效**：一个单一的Tier 1根节点（AG-01）的故障，准确地传播至其**6个传递后代节点**，而剩下的**10个节点**（包括其他3个Tier 1根节点）保持“有效”状态。这完美验证了“爆炸半径等于传递后代集合”的理论保证。
- **阻断等级与固有等级解耦**：被阻断的6个节点跨越了Tier 2和Tier 3，证明了阻断完全取决于图的位置，与其自身的风险等级无关。
- **匹配自举校准优于半分割校准**：
    - **匹配自举校准**：所有10个“验证有效”的Tier 1代理均被正确标记为“范围之内（Within Bounds）”，而所有被注入漂移的代理均被“硬标记（Hard Flag）”。
    - **朴素半分割校准**：同样的情况下，会错误地将**约90%** 的“验证有效”的Tier 1代理软标记为有漂移，产生极高的假阳性率。论文明确指出了产生这一现象的统计原因（样本量不匹配）。

### 7. 优点

- **系统性思维**：将智能体风险视为一个系统性问题，而非个体问题。其核心贡献在于提供了一个从发现、注册、验证到监控的完整、一致的治理闭环，而非一系列孤立的修复方案。
- **理论严谨性**：为“爆炸半径”提供了图论上的证明，确保了其控制的可预测性。对校准方法（匹配自举）的严谨性进行了数学和实证的深入分析，并指出了朴素方法的统计陷阱。
- **针对性强**：每个方法设计都明确指向解决一个特定的失效模式。例如，DoA评分解决“主导性问题”；阻断规则解决“高等级智能体被自动隔离”问题；匹配自举解决“假阳性”问题；两阶段响应解决“误报与检测延迟的权衡”问题。
- **实用导向**：涵盖了LLM版本变更、反馈循环、提示更改控制等实际操作中的棘手问题，使理论框架更具落地可能性。
- **可复现性**：提供了完整的模拟脚本，使其他研究者可以复现并验证其核心发现。

### 8. 不足与局限

- **严重依赖模拟**：整个框架的有效性仅通过模拟进行验证，缺乏在真实LLM驱动的大规模智能体系统中的端到端实践经验和性能数据。
- **CoT监控的假设**：框架依赖CoT作为“监控代理”和“黄金路径”的一部分。但如论文所述，CoT可能不忠实于模型内部的实际计算（即“解释不忠实性问题”）。因此，CoT漂移只是一个**必要但不充分的信号**。
- **静态嵌入模型假设**：“黄金路径”依赖于一个**固定的句子嵌入模型**。一旦该模型更新，所有积攒的“黄金路径”将立即失效。论文提出以版本锁定的方法来应对，但这会增加维护成本和风险。
- **初始校准依赖于独立同分布**：匹配自举校准的假阳性率控制依赖于“生产环境窗口数据与验证语料是同分布的”假设。实际生产数据可能存在时间自相关或协变量漂移，这会使得独立同分布自举的零分布过于乐观。论文将此列为开放问题。
- **未覆盖重要攻击向量**：虽然考虑了提示注入测试，但未系统性地考虑**对抗性轨迹操纵**问题——一个知道“黄金路径”的对手有可能构造既不触发漂移又能达成恶意目的的输出。
- **实验范围有限**：仅对一个特定场景进行了单一实验，缺乏对图结构、节点数和故障模式变化的敏感性分析。评估的充分性不足以支撑其结论的广泛适用性。
